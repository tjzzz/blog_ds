    【教程】Claudian插件安装指南 - 在Obsidian中直接用Claude Code#

    标题建议#

    在Obsidian里直接用Claude写代码？Claudian插件安装指南

    正文内容#

    想在Obsidian里直接调用Claude Code，不用切终端？一个插件搞定👇

    ✅ 安装前准备#

    1. 已安装 Obsidian - 桌面版（Mac/Win/Linux）
    2. 已安装 Claude Code CLI 
      # 验证是否已安装
which claude
claude --version

# 未安装的话
npm install -g @anthropic-ai/claude-code

    🔧 5步安装#

    Step 1 - 下载插件文件
    从 GitHub Releases 下载三件套：
    - main.js
    - manifest.json
    - styles.css

    📥 下载地址：github.com/YishenTu/claudian/releases

    Step 2 - 创建插件目录

    你的vault/.obsidian/plugins/claudian/

    Mac显示隐藏文件：Cmd + Shift + .

    Step 3 - 放入文件
    把下载的3个文件放进 claudian 文件夹

    Step 4 - 启用插件
    Obsidian → 设置 → 第三方插件 → 刷新 → 开启 Claudian

    Step 5 - 配置路径
    在插件设置里填 Claude Code 的绝对路径：

    /opt/homebrew/bin/claude  # Mac

    🎯 使用方法#

    • Cmd + P 打开命令面板
    • 搜索 Claudian 命令
    • 常用功能：
    • Chat - 与 Claude 对话
    • Improve Writing - 改进文本
    • Summarize - 总结内容
    • Generate Code - 生成代码

    💡 为什么用 Claudian？#

    • 直接在 Obsidian 里调用 Claude Code
    • 你的 vault 就是 agent 的工作目录
    • 直接读写笔记、搜索、执行多步骤任务
    • 免费开源，Claude Pro 订阅即可

    ⚠️ 注意事项#

    • 仅支持桌面版，移动端不能用
    • 需要填**绝对路径**，不要用 ~ 或相对路径
    • 笔记内容会发送到 Anthropic 服务器
