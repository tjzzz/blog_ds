# 合成控制法：为少数处理单元构造加权反事实

> [!abstract] 本页要解决什么
> 一个或少数城市、国家、门店接受干预且无单一可信对照时，能否用多个未处理单位的加权组合，在处理前复制处理单元轨迹，构造处理后反事实？SCM 的核心是处理前拟合质量与供体池可信度。

## 1. 目标量与直觉

设处理单位为 1，处理时点 $T_0$，供体池为未处理单位。选择权重 $w_j$，使合成单位处理前结果及预测因子尽可能接近处理单位。处理后的缺口为：

$$
\hat\tau_t=Y_{1t}-\sum_{j=2}^{J+1}w_jY_{jt},\quad t>T_0
$$

经典 SCM 通常要求权重非负、和为 1。权重应仅用处理前信息确定，不能依处理后效果挑权重。

## 2. 适用条件

- 处理单位很少，常见单一国家、城市或业务线；
- 处理时间明确，处理前序列足够长；
- 有多个未处理且未受溢出影响的供体；
- 处理前结果和关键预测因子可被良好拟合。

[Abadie、Diamond 与 Hainmueller (2010)](https://www.mit.edu/~jhainm/Paper/ccs.pdf)以加州烟草控制项目展示比较案例中的 SCM，并提出安慰剂式推断思路。

## 3. 实务步骤

1. 定义处理单位、处理时间、结果、供体池与效应窗口。
2. 根据制度和业务机制排除受干预溢出、同期政策或结构变化影响的供体。
3. 选择处理前结果序列和预测因子，不纳入处理后变量。
4. 估计供体权重并检查处理前拟合；拟合差则不要把合成组当可信反事实。
5. 比较处理后真实单位与合成单位，并按业务问题汇总动态/累计效应。
6. 做供体 placebo、时间 placebo、leave-one-out、不同供体池敏感性分析。
7. 报告权重、前期拟合误差、供体纳入理由、同期事件及推断局限。

## 4. 推断及与 DID 区别

少数处理单元下，常规大样本标准误并不自然。可把未处理供体逐一假设为“受处理单位”，比较缺口或处理前后误差比；这是置换/安慰剂式推断，不代表真的随机分配。供体少、前期拟合差时推断尤其有限。

经典 DID 依赖组间未处理趋势平行；经典 SCM 依靠加权供体拟合处理前轨迹。SCM 不会自动消除未观测混杂，也无法修复糟糕的前期拟合。处理单位多个时，可比较 DID 或扩展合成控制，但需审视各自目标和假设。

## 5. 失败信号

处理前拟合不佳、供体受同一干预波及、同期冲击不同、处理前太短、单一供体权重主导、只报告处理后差距而不报告权重/拟合误差，均应降级结论。高频用户数不会改变只有一个处理市场这一推断事实。
