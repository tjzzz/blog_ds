# 因果推断：从统计基础到业务决策

> 面向已有基础统计学知识、希望逐步掌握因果推断并在实际工作中评估策略的人。目标不是“学会套模型”，而是能够提出可识别的问题、设计可信比较、估计目标效应、诊断假设并给出有边界的决策建议。

## 一句话框架

**先定义要回答的因果问题（estimand），再判断能否识别（design + assumptions），最后才选择估计器与软件。** 复杂模型不能补救糟糕的研究设计；估计结果也不自动等于因果结论。

## 推荐学习路线

### 0. 统计学与研究设计预备
复习回归、抽样分布、置信区间/假设检验、方差与标准误、抽样偏差、缺失数据、面板/纵向数据，以及聚类标准误。无需先学高阶机器学习。先熟悉[统计学基础](../统计学基础/index.md)与[实验设计与AB测试](../实验设计与AB测试/index.md)。

### 1. 因果问题语言：问题 → estimand
读[因果推断导论](基础与识别/01_因果推断导论.md)、[潜在结果框架](基础与识别/潜在结果框架_ITE_ATE_ATT_CATE.md)及[潜在结果](基础与识别/潜在结果.md)。练习明确处理/干预、结果、分析单位、时间窗、目标人群、比较对象，并区分 ATE、ATT、CATE 等目标量。关键问题是“谁的什么处理，相对什么替代方案，在多长时间内，对什么结果的影响？”

### 2. 识别：为什么比较可以代表因果
读[结构因果模型：DAG 与 do-calculus](基础与识别/结构因果模型_DAG与do_calculus.md)和[偏差与识别假设](基础与识别/偏差与识别假设_混杂选择偏差内生性.md)。掌握混杂、选择偏差、碰撞点、反向因果、后处理变量、重叠性/正值性、一致性/SUTVA；画 DAG，确定调整集，说明不可检验的假设和潜在威胁。

### 3. 设计优先：先找最可信的对照
读[AB实验与因果推断的关系](基础与识别/AB实验与因果推断的关系.md)及[因果推断方法选择决策树](准实验方法/MOC_实验方法选择.md)。按“可随机化→随机实验；不可随机化→寻找自然实验/准实验；否则明确观察性识别假设”的顺序。准实验不是观察性方法的统称，更不是只要跑回归就有因果效应。

### 4. 经典设计与估计
按真实数据结构学习：[匹配与倾向得分](准实验方法/Matching与PSM.md)（可观测混杂下的重叠与平衡）、[DID](准实验方法/DID双重差分.md)（处理组/对照组的前后变化与平行趋势）、[RDD](准实验方法/RDD断点回归.md)（阈值附近局部效应）、[IV](准实验方法/IV工具变量.md)（外生鼓励/冲击及其局部效应）、[合成控制](准实验方法/合成控制法SCM.md)（少量受处理单位的反事实）。每种方法都要同时回答：目标效应是什么、识别靠什么、诊断什么、失败时结论如何降级。

### 5. 估计、推断、异质性与实践
在设计可信后学习回归调整、标准化/g-formula、IPW、双重稳健估计、DML 与[异质性处理效应/Uplift](准实验方法/异质性处理效应与Uplift.md)。先估总体效应与不确定性，再考虑人群异质性；异质性发现应避免多重检验、过拟合及把预测差异误当作已验证的可行动策略。

### 6. 软件与完整项目
先用透明的基础实现复现估计，再将工具作为工作流辅助：[StatsModels 实现](软件实现/CausalAnalysis__工具__08_工具_StatsModels实现PSM_DID_IV.md)、[DoWhy](软件实现/CausalAnalysis__工具__08_工具_DoWhy.md)、[EconML 与 CausalML](软件实现/CausalAnalysis__工具__08_工具_EconML与CausalML.md)。按“业务问题→研究方案→数据审计→估计→诊断/稳健性→解释/行动”完成一个案例。

## 实际工作标准流程

1. **决策问题**：这项结论会改变什么决策？定义处理、对照、结果、单位、目标人群、时间窗和目标效应；写出 estimand。
2. **画时间线与 DAG**：标明处理前/后变量、选择进入样本机制、共同原因、干扰/溢出与同期变化；不要用处理后变量控制总效应。
3. **选设计而非先选算法**：能做实验先评估随机化、污染、依从性和伦理；否则找阈值、分期、外生冲击、未处理单位/时段；再考虑条件可交换的观察性方法。
4. **审数据与可识别性**：样本纳入规则、处理定义、缺失、测量误差、重叠性、基线平衡/前趋势、聚类层级、处理时间及共同干预。若无可信识别设计，应报告关联而非因果效果。
5. **预先指定主分析**：主 estimand、模型、样本、协变量、标准误、诊断和敏感性分析；避免看结果后挑规格。
6. **估计并诊断**：报告效应量、区间估计、样本量/有效样本、假设诊断、安慰剂/负向对照（适用时）、替代规格及敏感性分析。显著性不是识别有效性的证明。
7. **翻译成决策**：说明适用人群/时间/场景、效应大小与不确定性、成本与副作用、外推限制、下一步验证方案；保留可复现代码与数据口径。

## 方法选择速查

| 观察到的数据/制度结构 | 候选设计 | 核心识别主张（不是自动成立） | 主要边界 |
|---|---|---|---|
| 可以分配处理 | 随机实验 / A/B | 随机分配使组间潜在结果可比；处理依从、干扰等仍需处理 | 溢出、非依从、选择性流失、实验外推 |
| 横截面/队列，处理前协变量丰富 | 回归调整、标准化、匹配、IPW、DR | 给定充分处理前协变量后无未测混杂，且有重叠 | 未测混杂、模型错设、极端权重 |
| 有处理组、对照组及前后时期 | DID / 事件研究 | 平行趋势及无破坏性同期冲击等 | 分期处理异质效应、提前反应、溢出 |
| 规则阈值决定处理概率 | RDD | 阈值处潜在结果连续、不能精确操纵 | 局部效应、带宽/函数形式敏感 |
| 外生鼓励影响处理但不直接影响结果 | IV | 相关性、排除限制、独立性；常需单调性解释 LATE | 弱工具、排除限制难论证、局部外推 |
| 少数处理单位、长前后序列与候选供体 | 合成控制 / 扩展合成控制 | 未处理供体加权后可逼近反事实，且无供体污染 | 单位少、前拟合不足、安慰剂推断有限 |
| 只想选择“更可能受益的人” | 异质性效应 / uplift | 上游效应识别成立，且异质性估计/验证可信 | 需要独立验证、政策价值不等于预测准确 |

该表是初筛，不是自动方法推荐。实际优先级取决于制度背景、数据生成过程与可捍卫的假设。

## 当前知识库盘点与缺口

已有内容覆盖：因果推断导论、潜在结果、DAG/后门、混杂和偏差、A/B关系；PSM、DID、RDD、IV、合成控制、Uplift；部分 Python 工具与学习资源。目录已可作导航，但不少文档混有旧笔记整合，需逐篇去重、核证公式/来源并补足实践诊断。

### 建议补建（优先级从高到低）

1. **因果问题定义、estimand 与目标试验模拟（高）**：研究问题模板、目标试验要素、ITT/TOT/PP、处理版本/一致性、时间零点和 immortal-time bias。连接业务决策与可估计量。
2. **调整集、DAG 与选择偏差专题（高）**：混杂/中介/碰撞点、何时调整、缺失与选择机制；现有 DAG 笔记适合入门，但应有可操作案例。
3. **观察性研究估计器与识别（高）**：回归调整、g-computation、IPW、AIPW/TMLE 的直觉和条件、倾向得分不等于“消除混杂”；现有 PSM 不能代表全部调整方法。
4. **标准误、区间估计与聚类推断（高）**：聚类随机化/处理分配层级、小簇问题、bootstrap、多个检验与报告规范；否则业务显著性容易被误读。
5. **DID 现代设计与事件研究（高）**：分期处理、效应异质性下传统 TWFE 风险、组别-时间 ATT、事件研究诊断与推断；现有 DID 页需专门更新这一块。
6. **敏感性分析、负向对照与稳健性（高）**：未观测混杂敏感性、安慰剂、负向对照、规格曲线、研究者自由度；“做了稳健性检验”不等于假设已证明。
7. **实验进阶与干扰（中）**：簇随机、网络/市场干扰、鼓励设计、非依从、流失、实验污染、switchback/地理实验，与现有 A/B 文档衔接即可，避免重复维护。
8. **面板与时间序列干预设计（中）**：中断时间序列、BSTS/CausalImpact、合成控制扩展；现有决策树提及但无独立方法页，且须写清对照与时间序列假设。
9. **中介、机制、连续/多值处理、动态处理（中）**：处理效应机制与时间变化处理的额外假设，避免把相关机制分析当因果机制。
10. **迁移与政策评估（中）**：外部效度、运输性、成本效益/决策规则、异质性策略的前瞻性验证；把效应估计真正连到实际应用。
11. **统一案例与数据实践（高）**：一份从问题、DAG、模拟数据、主分析、诊断到报告的纵向案例；每种方法增加可运行 notebook/代码、数据字典、复现环境和输出模板。
12. **知识源与文献维护（中）**：为每篇方法笔记建立原始论文/权威教材链接和“适用范围、假设、诊断、常见误用”标准结构；软件/API 单独注明核验日期，避免过时代码。

建议先补 1–6 与统一案例，再扩展专题；不要为了“全面”先堆更多算法名称。
