    2 学习资源—他山之石#

    在学习数据分析方面，有很多优秀的学习资源可以选择。以下是一些值得推荐的资源：

    1. Coursera：提供了很多数据分析相关的课程，包括数据分析基础、数据可视化、机器学习等。

    2. Kaggle：一个数据科学竞赛平台，可以参加各种数据分析和机器学习竞赛，也可以浏览其他人的解决方案学习。

    3. DataCamp：一个在线学习平台，提供了很多数据分析和机器学习的课程，可以通过练习来巩固所学知识。

    4. Udacity：提供了很多数据科学相关的课程，包括数据分析、机器学习、深度学习等。

    5. GitHub：一个代码托管平台，可以在上面找到很多数据分析和机器学习的开源项目，也可以自己上传自己的代码和项目。

    6. Stack Overflow：一个问答社区，可以在上面提问和回答关于数据分析和机器学习的问题。

    以上这些资源都是非常优秀的，可以根据自己的需求和兴趣选择适合自己的学习资源。

    3. 学习路线#

    如果你是一个数据分析的小白, 不知道，如何学习数据分析，那么我建议你从最基础的地方开始入手。
    如果你懂得一些基础的分析方法，也知道如何做数据可视化，但是希望能在工作中增加一些有增益有亮点的技能。那么你可以学习一些高阶的分析思路，以及一些简单的机器学习模型。能在数据分析的基础上增加一些模型技能的亮点。

    如果你已经是一个有很多年经验的从业人员，分析技能和技巧相对比较完善。那么这个时候建议你从业务的角度入手，站在业务全局去思考问题。要解决的核心业务问题是啥，整体的业务链路以及数据流程是如何的，然后再去思考能做哪些去提升业务表现。这个时候的技术技能显得并不是那么重要，关键的是如何定义问题、发现问题、然后解决问题。

    为此，打算写一个系列，你可以按照自己的需求进行按图索骥，拼接自己的技能。

    2. 学习编程语言：数据分析需要编程语言来完成数据处理、分析、可视化等任务。Python 和 R 是最常用的编程语言，你需要学会其中之一。你可以通过网络课程、书籍或者视频教程来学习 Python 或 R 编程语言。
