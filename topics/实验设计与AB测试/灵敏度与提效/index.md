实验敏感性不足，指的是：**实验真实存在效果，但因为样本量、指标方差、实验设计或指标选择问题，实验很难把这个效果稳定检出来**。

什么时候要怀疑敏感性不足：

| 现象 | 可能原因 |
|---|---|
| 指标方向稳定正向，但一直不显著 | 样本量不足、方差太大、MDE 过小 |
| 分层里部分人群明显正向，整体不显著 | 人群异质性强，被整体平均稀释 |
| 小改动业务上合理，但 AB 完全看不出 | 指标不敏感，或者实验方式不适合 |
| 金额、时长类指标波动极大 | 长尾分布、极端值拉高方差 |
| 长期指标看不出，短期指标有变化 | 指标窗口太长、转化低频 |
| 搜索排序微调没有信号 | AB 对排序微调不敏感，可能需要 interleaving |


一句话：

> 实验敏感性解决的是：为什么业务上可能有用的策略，在实验结果里看起来“不显著”。

## 1. 先看公式：为什么会“不敏感”

在 AB 实验里，常见检验统计量可以直观理解为：

$$
t = \frac{\bar Y_t - \bar Y_c}{\sqrt{Var(\bar Y_t - \bar Y_c)}}
$$

如果两组样本量相同，可以近似写成：

$$
t = \frac{\bar Y_t - \bar Y_c}{\sqrt{\sigma_t^2/n + \sigma_c^2/n}}
$$

所以实验是否容易显著，取决于三件事：

| 因素 | 影响 |
|---|---|
| 组间差异 | 实验组和对照组差异越大，越容易显著 |
| 样本量 | 样本量越大，标准误越小，越容易显著 |
| 指标方差 | 指标方差越大，噪声越大，越不容易显著 |

提高实验敏感性，本质上就是：

```text
放大可检测的真实差异，或降低指标噪声。
```

## 2. 提效地图：先判断瓶颈在哪一环

提高实验敏感性不只有“降低方差”一条路。先判断问题来自样本信息量、指标分布、基线预测能力、人群结构，还是实验机制，再选择方法。下表是本专题的导航地图；同列在一张地图中不代表它们属于同一种算法。

| 路线 | 代表方法 | 主要作用 | 类型与边界 | 深入阅读 |
|---|---|---|---|---|
| 增加信息量 | 增加样本/流量、延长周期、优化组间分配比例 | 降低抽样标准误 | 设计与资源优化，不是估计器；需权衡实验风险、周期趋势和流量机会成本 | [方法一](#3-方法一增加样本量与优化流量分配) |
| 改善结果指标 | 截尾、winsorize、log/其他变换、分位数指标 | 降低极端值影响或改变结果尺度 | 指标处理，不属于 CUPED；可能改变 estimand，应事前确定 | [方法二](#4-方法二降低指标方差) · [指标变换与实验敏感性](指标变换与实验敏感性.md) |
| 协变量调整 | CUPED、多协变量回归、CUPAC、MLRATE、STATE | 利用预处理信息预测结果中的自然波动，降低处理效应估计方差 | CUPED 是基础方法；CUPAC/MLRATE 是其 ML 扩展；STATE 进一步把误差分布改为 Student-t 以适配重尾指标 | [CUPED](CUPED.md) · [CUPED 变体](CUPED变体.md) · [STATE](STATE.md) |
| 分层与加权 | 分层随机化、后分层、方差加权 | 利用已知人群结构改善分配平衡或汇总估计 | 分层随机化发生在实验设计阶段；后分层发生在分析阶段。与 CUPED 相关但不是同一种协变量调整 | [方法四](#6-方法四分层与后分层) |
| 其他因果估计器 | Doubly Robust（DR）/ AIPW | 结合结果模型与处理分配概率估计处理效应 | 因果效应估计框架，不是“更复杂的 CUPED”；稳健性依赖识别条件和模型设定 | 本页方法地图；若需要系统学习可参见[因果推断](../../因果推断/index.md) |
| 选择信号 | 近端/机制指标、触发用户辅助分析 | 让实验更早观察到机制信号 | 不一定降低同一估计量的方差；触发用户分析不能随意替代随机化总体分析 | [方法五](#7-方法五选择更敏感的指标与触发用户分析) |
| 适配实验设计 | interleaving、配对/区组/交叉、集群或 switchback 设计 | 减少无关差异，或适配干扰与依赖结构 | 与估计方法不同；随机化单位、 estimand 和标准误必须相匹配 | [方法六](#8-方法六换实验机制或实验设计) · [interleaving](../实验流程与设计/实验方法选择.md#Interleaving：排序系统的在线比较) |

> **术语边界**：CUPED 是协变量调整；分层随机化是实验前的分配设计；后分层是分析阶段的分层加权；DR 是因果效应估计框架。它们可以互补，但不是相互替代的同义词。

下文按六类常见业务动作展开。DR 等不属于 CUPED 的相关路线仅在地图中定位；CUPED 的扩展细节集中在 [CUPED 变体](CUPED变体.md)。

> 本专题所有「提高灵敏度 / 降低方差」方法的来源、证据类型、论文/案例**实测提升效果**与推荐筛选，已汇总至 [方差缩减方法清单](方差缩减方法清单.md)（含 CUPED/CUPAC/MLRATE/Rank/Re-randomization/Instacart 等量化数据）。

## 3. 方法一：增加样本量与优化流量分配

这是最直接的方法。

可以通过：

- 提高实验流量；
- 拉长实验周期；
- 扩大目标人群；
- 减少不必要的排除规则；
- 合并多个低频场景；
- 在风险可控时，让实验组和对照组尽量接近 50/50，提高统计效率。

但增加样本量不是万能的：

| 风险 | 说明 |
|---|---|
| 周期太长 | 外部环境、版本发布、节假日更容易干扰 |
| 流量太大 | 如果策略有风险，会扩大损失 |
| 人群扩大 | 可能引入不相关人群，稀释真实效果 |
| 机会成本 | 占用流量层，影响其他实验排期 |

## 4. 方法二：降低指标方差

很多业务指标天然长尾，例如 GMV、停留时长、订单金额、人均收入。少数极端用户可能让指标方差变得很大。

常见处理：

| 方法        | 说明                  |
| --------- | ------------------- |
| 截尾        | 去掉极端高值或低值           |
| winsorize | 把极端值压到某个分位点，而不是直接删除 |
| log 转换    | 对强长尾金额类指标做对数变换      |
| 分位数指标     | 用中位数、P75、P90 替代均值   |

注意：指标变换必须在实验前定义，不能实验后为了显著性临时换口径。

更深入的指标变换与实验敏感性分析（样本量公式、log 闭式节省比、机制依赖表、收入/时长分机制建模、验证流程）见 [指标变换与实验敏感性](指标变换与实验敏感性.md)。

## 5. 方法三：CUPED 方差缩减

CUPED（Controlled Experiment Using Pre-Experiment Data）的核心思想是：

> 如果实验前的历史行为 X 和实验期目标指标 Y 高度相关，而且 X 不受实验影响，就可以用 X 来解释一部分 Y 的自然波动，从而降低方差。

直观理解：用户实验前的历史行为可以解释一部分实验期结果的自然波动。

对结果 $Y_i$ 使用处理前协变量 $X_i$ 调整，常见写法为：

$$
Y_i^{\text{cuped}} = Y_i - \theta (X_i - \bar X)
$$

如果 X 和 Y 的相关系数为 $\rho$，理想情况下有：

$$
Var(Y') = Var(Y)(1 - \rho^2)
$$

所以 X 和 Y 越相关，方差降低越明显。

例子：

| 实验指标 Y | 可用协变量 X |
|---|---|
| 实验期下单数 | 实验前一周下单数 |
| 实验期 GMV | 实验前一周 GMV |
| 实验期点击率 | 实验前历史点击率 |
| 实验期活跃天数 | 实验前活跃天数 |

使用 CUPED 的注意点：

- 协变量必须在实验开始前产生；
- 协变量不能受实验处理影响；
- 协变量和目标指标要有足够相关性；
- 新用户或无历史数据用户可能不适用。

完整推导、实施流程与常见误区见 [CUPED](CUPED.md)；CUPAC、MLRATE、STATE 等扩展与选型见 [CUPED 变体](CUPED变体.md)；面向长尾指标的 STATE 稳健估计单独见 [STATE](STATE.md)。

## 6. 方法四：分层随机化与后分层

当已知人群特征会影响结果时，可以考虑分层，但要区分两个阶段不同的做法：**分层随机化**在实验开始前按层分别随机分配处理组/对照组；**后分层（post-stratification）**在实验结束后按预先定义的层估计效果，再按目标总体结构加权汇总。二者都利用已知人群结构，但不等同于 CUPED 的协变量回归调整。

常见分层变量包括：

- 新用户 / 老用户；
- 高活 / 中活 / 低活；
- iOS / Android；
- 城市等级；
- 商家等级；
- 流量来源。

在后分层分析中，按层估计效果后再按目标总体结构加权汇总；分层随机化则是在每一层内分别随机分组。

可能的好处：

- 提高关键人群特征上的组间平衡；
- 按目标人群构成汇总，减少偶然构成差异的影响；
- 帮助描述效果异质性，但不能事后挑选显著分层。

### 6.1 方差加权估计

在 post-stratification 的基础上，如果不同 group 的方差差异很大，可以进一步考虑 **variance-weighted estimators**。

直觉是：

```text
同样都是一个分层估计值，噪声更小的层可以给更高权重，噪声更大的层给更低权重。
```

只要权重设计不引入系统性偏差，这类估计量仍然可以保持无偏，同时降低总体估计方差。

适用条件：

- 已经有稳定分层，例如新老用户、端、地域、用户活跃度；
- 各层样本量和方差差异明显；
- 平台能稳定记录层标签；
- 权重规则在实验前定义，而不是实验后为了显著性临时调权。

注意：方差加权不是“让结果更好看”，而是让估计更有效率。它应该服务于更稳定的估计，而不是服务于选择性汇报。

## 7. 方法五：选择更敏感的指标与触发用户分析

有时候不是实验没效果，而是指标离实验动作太远。

例子：

| 实验动作 | 不够敏感的指标 | 更敏感的前置指标 |
|---|---|---|
| 搜索排序优化 | GMV | 长点击率、满意点击率、换 query 率 |
| 推荐卡片样式 | 次日留存 | 点击率、停留时长、负反馈率 |
| 下单页文案 | 复购率 | 提交订单率、支付转化率 |
| 新手引导 | 30 日留存 | 首日关键行为完成率 |

前置指标不能替代最终指标，但可以帮助判断机制是否生效。

如果实验触发率很低，也可以补充观察「真正触发实验处理的人群」，例如真正看到新样式、真正进入改造链路、真正被新排序策略影响的用户。但触发用户分析通常是辅助分析，不能随意替代全量随机人群口径，否则可能引入触发偏差。

## 8. 方法六：换实验机制或实验设计

如果改动非常细，普通 AB 可能天然不敏感。

典型场景是搜索 / 推荐排序实验：

- 排序位置只发生微调；
- 低频 query 很难在实验组和对照组同时出现；
- 用户行为差异被 query 差异掩盖。

这时可以考虑 [interleaving](../%E5%AE%9E%E9%AA%8C%E6%B5%81%E7%A8%8B%E4%B8%8E%E8%AE%BE%E8%AE%A1/index.md)：让同一次请求中同时混排两个策略的结果，用点击和停留等行为判断用户更偏好哪一侧。

如果业务对象天然可以配对或分块，也可以考虑配对实验、区组实验、交叉实验、自身前后对照等设计，让实验组和对照组在关键背景变量上更接近，从而减少无关差异。

## 9. 不要为了敏感性牺牲可信度

提高敏感性时要避免几类错误：

| 错误做法 | 问题 |
|---|---|
| 实验后临时换指标 | 容易 p-hacking，增加假阳性 |
| 只看正向分层 | 多重检验问题，容易误判 |
| 只看触发用户 | 可能产生触发偏差，破坏随机性 |
| 任意剔除异常值 | 可能人为制造显著性 |
| 无限延长实验 | 容易受到时序干扰和外部冲击 |

原则：

> 敏感性提升必须在实验前设计，不能在实验后为了显著而改口径。
