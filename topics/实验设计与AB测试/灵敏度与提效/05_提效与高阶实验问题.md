# 提效与高阶实验问题

> 父级入口：[实验设计与AB测试](../index.md)

## 定位

这个子 topic 负责收纳标准 AB 之外的实验提效方法和疑难问题：方差缩减、pre-AA、CUPED、网络效应、触发偏差、辛普森悖论、长期效应等。

## 核心问题

- 样本不足或方差过大时，如何提升实验灵敏度？
- A/A、pre-AA、CUPED/CUPAC 在实验前后分别解决什么问题？
- 网络效应、溢出干扰、时序干扰、长期效应会如何破坏标准 AB 结论？
- 触发偏差、幸存者偏差、辛普森悖论如何识别和修正？

## 问题地图

| 问题类型 | 典型表现 | 优先排查 / 方法 |
|---|---|---|
| 方差过大 | 指标波动大、样本量需求高 | CUPED/CUPAC、分层、稳定指标、延长周期 |
| 分流异常 | 样本比例不匹配、基线不均衡 | SRM、hash 分桶、实验单元、曝光埋点 |
| 显著性窥探 | 中途看结果并停止，假阳性升高 | 序贯分析、alpha spending、事前停止规则 |
| 多重检验 | 多指标/多分层里总能找到显著 | 主指标优先、校正、探索/验证分离 |
| 网络效应 | 实验组影响对照组 | cluster randomization、地理实验、干扰建模 |
| 触发偏差 | 只分析触发人群导致选择偏差 | 同时报告 ITT 与 triggered analysis |
| 长期效应 | 短期指标好，长期留存/生态变差 | holdout、长期窗口、观测指标 |
| 辛普森悖论 | 总体和分层方向相反 | 固定分层口径、检查构成变化 |

## 提效优先级

1. **先修数据质量**：错误分流、埋点缺失、口径漂移不能靠统计方法补救。
2. **再降方差**：优先选择更稳定、更靠近实验机制的指标；再考虑 CUPED/CUPAC。
3. **再优化设计**：分层随机、合适实验单元、合理周期和流量比例。
4. **最后换方法**：序贯、MAB、HTE 等方法必须匹配业务目标和决策规则。

## 沉淀建议

每次遇到异常实验，都在实验报告中单独记录：异常现象、排查路径、根因、是否影响结论、下次预防规则，并回链到本页对应问题类型。
