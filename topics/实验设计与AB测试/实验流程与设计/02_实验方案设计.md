# 实验方案设计

实验方案要在分配流量前回答：**验证什么、对谁验证、比较什么处理、测量什么结果、需要多少信息、何时分析，以及什么结果将触发什么行动？**

## 方案一页表

| 要素 | 预先写清什么 |
|---|---|
| 业务问题/假设 | 要改变什么行为或结果？预期方向是什么？ |
| 估计目标 | 目标总体、处理对比、主要结果及观察窗口；说明是分配效果还是触发/曝光效果 |
| 随机化设计 | 随机化单位、分配比例、分层/集群策略及稳定分桶规则 |
| 实验人群 | 准入、排除、触发和分析人群规则；规则在两组一致并事前固定 |
| 处理版本 | Control 和每个 Treatment 的功能、策略、参数、默认回退及版本标识 |
| 指标与统计 | 核心指标、护栏、口径、MDE/业务门槛、显著性/功效和多重性处理 |
| 周期与流量 | 计划样本/信息量、流量比例、成熟窗口、最大运行时间和放量节奏 |
| 监控与停止 | 质量/安全巡检；固定终点或序贯查看；效果、无效、风险停止规则 |
| 并行与干扰 | 与其他实验互斥/正交/依赖关系、污染和网络效应处理 |
| 决策与记录 | 分析负责人、业务决策人、上线/回滚条件、后续监控与记录位置 |

## 1. 明确问题、假设与目标

把“这个功能效果好不好？”改写成可比较的问题，例如：

> 对目标人群，在预设的观察窗口内，Treatment 相对 Control 是否提高核心指标，并达到最小业务收益要求，同时不使护栏超过可接受风险？

实验假设至少说明：

- **目标人群/场景**：结论希望适用于谁？
- **处理对比**：哪些版本/策略有何差异？
- **主要结果**：哪个指标、哪个时间窗口？
- **目标效果/门槛**：最小业务有意义的提升或可接受损害是什么？
- **风险约束**：哪些护栏不能越界？

统计假设形式应与问题对应。例如均值差可以写为 $H_0:\Delta=0$ 与 $H_1:\Delta\ne0$；如果业务关注是否超过一个正向门槛，统计问题与判定边界要明确区分。单侧检验只在方向和反向风险均有事前理由时使用。

## 2. 选择目标人群、实验单位和处理

### 目标人群

定义准入、排除、触发和分层规则。分配前确定的排除规则适用于两组；不要按结果事后删选用户。若只对“实际触发/曝光”人群估计效果，须说明该分析对应的估计目标，并确认这种筛选不会引入处理后选择偏差；默认主分析通常按原始随机分配进行（ITT 思路）。

### 实验单元与分析单位

实验单元是被随机分配的单位，如用户、设备、商家、门店、内容或请求。选它时考虑干预如何生效、单位间是否会相互影响、用户是否跨设备/跨组，以及指标怎样聚合。分析单位和随机化单元不同（例如按商家随机、订单记录结果）时，要按真实相关结构计算不确定性，不能把相关订单当独立样本。

### 处理与版本

明确 Control、各 Treatment、多版本间的差别、参数、开始/停止条件、流量开关及安全回退。运行中版本或准入规则变更须记录；若改变了处理定义或实验数据生成机制，可能需要重新起算或重新分析，不能无记录地并入同一实验。

### 时间窗口

区分招募/分流期、处理期、指标观察窗口、转化归因窗口和数据成熟/回收期。周期要覆盖重要的业务周期（如完整周内模式），也要满足低频/延迟指标的观察需求。达到计划样本数不等于所有结果都已成熟。

## 3. 选择合适的实验设计

方法选择由 estimand、随机化条件、干扰和业务风险决定。常见选择与边界见[[实验方法选择]]。可行性分析阶段判断“能否随机/是否值得做”，本节才把选择落实到实际分配方案。

要至少确定随机化层级、组数、分流比例、分层变量、组间隔离、并行实验关系和异常处置。强网络效应、集群处理或系统级策略不能机械套用户级独立 A/B；必要时按集群/地域随机或使用其他识别设计，并记录分析方法。

## 4. 指标、样本量和流量规划

主要指标、指标口径和统计计划详见[[03_指标体系与显著性]]。实验前应决定业务上最小值得检测/接受的效果，再根据基线率/方差、显著性水平 $\alpha$、目标功效、组间比例、随机化与分析结构等规划所需信息量。

以两组独立、等样本量、二元指标为直觉示例：对照基线率约为 $p$，每组样本量为 $n$，两组率差估计量的标准误近似为

$$
SE(\hat p_T-\hat p_C)\approx\sqrt{\frac{2p(1-p)}{n}}.
$$

在正态近似、双侧显著性水平 $\alpha$ 和目标功效 $1-\beta$ 下，比例差的近似 MDE 可写为

$$
MDE\approx (z_{1-\alpha/2}+z_{1-\beta})\sqrt{\frac{2p(1-p)}{n}}.
$$

这里是规划直觉，不是所有指标的通用计算器。实际计算需使用与终点、分配比例、统计检验、聚类/重复观测、方差缩减和多重性相匹配的方法；稀有事件、小样本或高偏态数据可能需要更适当模型/模拟。MDE 是设计属性，不能因实验结果不显著而事后改写。

### 样本与运行时间的常见取舍

- 更小的目标差异、更严格的错误率、更高功效、指标更高方差，通常要求更多样本。
- 50/50 在常见两组、单个结果、每个单位采集成本相近的设定下通常有较好统计效率；风险、安全、成本或流量治理可能要求不等比例。
- 低流量、稀有转化、延迟成熟会延长运行时间。先核对可达样本和业务可接受周期，再决定是否改变设计/指标，而非跑不出显著就不断延长。
- 若要求实验中途依据效果停止，按预先定义的序贯设计规划；不能先用固定样本量，再临时添加“显著就停”。见[[../统计判断与决策/序贯分析]]。
- 若敏感性不足，先识别原因并评估可用方法，见[[../灵敏度与提效/index|灵敏度与提效]]。

## 5. 流量分配、并行和放量

计划流量比例要满足统计精度与风险控制。标准两组比较常见均衡分配；高风险场景可以先小流量检查安全和实现，再进入正式的效果验证阶段。每次扩量须有明确退出条件。具体配置与流量层架构见[[../分流与平台/index|分流与平台]]。

并行实验关系应在方案里声明：

- **互斥**：避免两个处理同时影响同一单位或同一结果；
- **正交/独立分流**：如果同时运行，要确认组合设计与目标效应可解释，必要时评估交互；
- **依赖/嵌套**：记录依赖关系和实际处理路径；
- **隔离/专用流量**：用于高风险或影响核心链路的实验。

## 6. 预设分析和决策

上线前固定：主分析人群、主要指标、估计量、主要比较、统计方法、查看频率/时点、停止边界、多重比较、护栏阈值，以及发现数据质量异常后的处置。预先定义探索性问题和确认性问题，避免事后挑选。

将“统计结果”与“行动”连接起来，但不混为同一门槛：

| 证据/情境 | 预设动作示例 |
|---|---|
| 主要效果证据达到设计规则，业务收益过门槛，护栏安全 | 分阶段放量/上线，并持续监控 |
| 不确定区间仍覆盖有价值正效应和不可接受负效应 | 按设计继续收数或报告不确定，不能称为等效 |
| 护栏风险触发 | 按安全规则暂停/回滚，不等待主指标显著 |
| 分流或数据异常 | 暂缓效果结论，先诊断数据链路 |
| 到最大样本/时限仍不明确 | 报告不确定性与限制；不事后改变终点来追显著 |
