# 实验指标体系与统计规划

指标不是实验结束后挑一个显著结果，而是方案的一部分。事前定义指标的业务含义、统计口径、数据窗口和判断职责，才能解释“变化了多少、是否可信、是否值得行动”。

## 1. 建立指标层级

| 指标类别 | 回答的问题 | 用法 |
|---|---|---|
| **核心指标** | 实验主要目标是否实现？ | 少而明确，作为主要判断对象；有多个主指标时预先安排多重性处理 |
| **辅助/诊断指标** | 核心指标为什么变化？链路哪一步变了？ | 解释机制，通常不单独作为上线理由 |
| **护栏指标** | 是否以伤害体验、稳定性或风险为代价？ | 预设可接受界限和处置动作；必要时触发暂停或回滚 |
| **观测指标** | 是否存在长期、间接或局部影响？ | 用于监测和提出后续假设；探索性发现应标记并验证 |

核心指标直接对应业务假设；护栏是不可接受损害的边界。二者的决策作用不同，不应因为一个核心指标正向就忽略护栏风险。

## 2. 把指标口径写成可复现定义

方案至少要写明：

- 名称、业务含义、方向（越高越好/越低越好）及单位；
- 分子、分母、去重单位，统计/随机化单位之间如何对应；
- 纳入人群、触发/曝光条件、缺失和异常值处理；
- 观察窗口、归因窗口、事件成熟/数据回收时间；
- 数据源、日志关联方式、版本和口径负责人；
- 业务最小有意义效果，以及护栏的预警/阻断规则。

例如，“支付转化率”需说明分母是被随机分配用户、触发用户还是支付页曝光用户；如果分母依赖实验后的行为，比较人群可能不再保持随机可比，须明确估计目标并谨慎解释。

## 3. 效果、统计与业务判断要分开

预先规定主要估计目标（如实验组减对照组的用户级转化率差）、假设方向、分析方法与终点。样本量规划要把业务关心的最小效果（MDE）、基线水平/方差、显著性水平 $\alpha$、目标功效、分流比例及数据相关结构联系起来。MDE 是设计参数，不代表实际效果，也不必然等于上线业务门槛。

实验报告至少分别回答：

1. **效果多大、方向如何？** 报效应估计及单位。
2. **不确定性有多大？** 报匹配的置信区间/后验区间及方法。
3. **统计规则是否支持判断？** 按预设检验、区间或序贯规则陈述。
4. **业务上是否值得？** 对照最小业务门槛、成本和护栏决定行动。

$p<0.05$ 不等于效果大或值得上线；$p\geq0.05$ 也不证明效果为零。若有多指标、多版本或事后切片，要预先声明确认性比较族和探索分析的边界。反复查看则是额外的时间维度问题，见[[../统计判断与决策/序贯分析]]。

## 4. 指标敏感性与特殊场景

检出能力由效果大小、样本量与指标变异共同决定；长尾、重复观测、聚类或强人群异质性会影响方差和标准误。优先使用与随机化/分析单位相符的估计方法，不以“换一个显著指标”解决功效不足。

方差缩减、CUPED、指标变换与 pre-AA 等提升方法见[[../灵敏度与提效/index|灵敏度与提效]]。搜索/推荐排序的局部排序变化也可能考虑 Interleaving，但应使用适当的排序评价和归因方案，不能把它简单等同于用户级 A/B；见[[实验方法选择#Interleaving：排序系统的在线比较]]。

## 5. 指标方案模板

```text
业务目标 / 假设：
目标人群、实验单元：
核心指标（定义、分子/分母、方向、单位）：
观察窗口与成熟规则：
最小业务有意义效果：
统计设计（MDE、alpha、power、最大样本/终点）：
辅助/诊断指标：
护栏指标与暂停/回滚阈值：
多指标/多版本/切片处理：
数据来源、埋点与质量检查：
分析计划与决策责任人：
```

## 一个指标定义示例

“7 日支付转化率”可以具体写成：随机分配到该组的合格用户中，在首次符合定义的实验曝光后 7 天内至少完成一笔已支付且未取消订单的用户比例。实现前仍需确定：曝光是分子/观察窗口起点，跨设备如何归并，同一用户多单如何去重，退款/取消的成熟时间，以及分母采用分配用户还是触发用户。这个例子是口径模板，不是通用指标定义；换一个业务问题，估计目标也可能不同。

## 常见误区

- 事后新增主指标或改变分母/人群，让结果“变好看”；
- 把统计显著、业务显著、护栏安全视为一回事；
- 以“没显著”代替等效/非劣结论；
- 把多个指标或多个人群切片当作彼此独立的确认性检验；
- 把触发后的用户子集直接当作随机样本，而不检查选择偏差；
- 用普通固定终点区间解释被反复窥探或数据依赖停止的结果。
