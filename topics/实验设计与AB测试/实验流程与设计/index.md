# 实验流程与设计

返回[实验设计与AB测试](../index.md)。本专题按实验生命周期组织内容：**判断是否适合实验 → 设计方案与指标 → 执行和监控 → 分析与复盘**。指标与统计规划是实验方案的一部分，因此纳入本专题入口，但保留独立的方法边界。

## 建议阅读顺序

1. [[00_实验生命周期与上线治理]]：先建立从立项、校验、运行到上线后复盘的全景。
2. [[01_实验可行性分析]]：确认问题是否值得、是否适合用随机实验回答。
3. [[02_实验方案设计]]：定义 estimand、人群、随机化、样本/窗口、监控与行动规则。
4. [[实验方法选择]]：需要时再选择 A/B、分层/区组、析因或 Interleaving 等设计。
5. [[03_指标体系与显著性]]：事前定义指标口径、样本量参数及统计/业务判断。
6. [[实验结果与全量差异排查]]：实验结论与全量上线表现不一致时使用。

## 按问题查阅

### 生命周期与上线治理

- [[00_实验生命周期与上线治理]] — A/A/空转、灰度、正式分析、回滚、holdout 和复盘。
