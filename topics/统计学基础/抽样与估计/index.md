# 抽样与估计

关注如何获得可解释的数据、样本能代表什么总体，以及估计精度由什么决定。概率抽样支持设计型推断；便利样本不能仅靠扩大样本量消除选择偏差。

## 笔记目录
- [[抽样技术__抽样技术]] — 概率/非概率抽样、线上 hash 抽样与流量分层
- [[参数估计-样本量的确定]] — 由精度或功效目标规划样本量
- [[抽样技术__调查问卷的信度、效度]] — 测量的一致性与构念有效性

## 阅读时的检查点
总体/抽样框是否清楚？纳入概率、无应答、聚类和分层是否影响方差？样本量计算中的置信水平、误差界、效应量、方差先验与检验方向是否写明？信度高不代表效度高。
