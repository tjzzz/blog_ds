# 统计学基础

统计学不是一组“显著性检验公式”，而是一条从**目标问题—数据生成—样本设计—统计量—不确定性—结论边界**的推理链。它帮助我们描述观察到什么、估计总体未知量、比较假设，并判断数据是否足以支持决策；它本身不能自动修复偏差，也不能仅凭相关性证明因果。

## 本 Topic 要回答的问题

1. 数据是如何产生、测量和抽取的？样本能代表谁？
2. 想描述或估计的总体量（estimand）是什么，估计误差有多大？
3. 观察到的差异与随机波动相比有多大？结论是否有实际意义？
4. 方法依赖哪些假设，偏离假设会怎样？结果可推广到什么范围？

## 核心推理链

**定义目标总体与 estimand → 设计测量/抽样 → 描述数据与检查质量 → 建立概率模型 → 估计效应及不确定性 → 按设计选择检验/模型 → 解释效应量、区间与边界 → 作决策并复核。**

概率分布描述随机变量和统计量的行为；抽样分布连接样本与总体；标准误量化估计量的抽样波动；置信区间表达与数据相容的参数范围；检验则评估在指定原假设下数据的极端程度。它们都依赖抽样/随机化设计和模型假设。

## 方法选择的最小决策表

| 目标 | 首先明确 | 常见方法入口 | 关键警惕 |
|---|---|---|---|
| 描述样本 | 变量类型、分布、缺失与异常 | 描述统计、图形、分位数 | 不把样本描述冒充总体结论 |
| 估计一个总体量 | estimand、抽样设计、精度 | 参数估计、置信区间 | 标准误需匹配设计；偏差不会因样本变大自动消失 |
| 比较组间差异 | 随机化/配对/独立结构、指标口径 | t/Welch、比例/列联表检验、ANOVA | 直接估计差值及区间，不用“各组区间重叠”替代差异检验 |
| 评估关联或预测 | 结果类型、协变量、函数形式 | 线性/广义线性回归 | 相关、预测和因果效应是不同目标 |
| 处理复杂/偏态数据 | 目标参数与数据生成机制 | 稳健、非参数、重抽样方法 | 非参数不意味着“无假设” |
| 生存/时长结果 | 起点、事件、删失机制 | Kaplan–Meier、log-rank、Cox 等 | 删失需合适处理；普通均值比较会丢失信息 |

## 贯穿全篇的概念

- **总体参数**是目标总体的特征；**样本统计量**是从样本算出的量；**估计量**是抽样前的随机变量，观察到的数据给出其估计值。
- **标准差**描述个体观测离散度；**标准误**描述统计量跨重复抽样的波动。样本量增加通常减小标准误，但不必然减少选择偏差或测量误差。
- **统计显著性**不等于效应大、重要或可复现。报告效应量、区间、设计和假设，避免只报 p 值。
- **未拒绝原假设**不是证明原假设为真。若要论证“足够接近/不劣”，应预先定义等效界值并使用等效/非劣效框架。
- **模型检查**与数据质量检查不可省略；多重比较、可选停止、缺失、依赖、聚类和干预污染会改变误差控制与推断。
