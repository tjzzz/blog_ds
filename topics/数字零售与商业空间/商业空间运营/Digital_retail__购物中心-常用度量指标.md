# 常用度量指标

## 衡量零售店能力的度量指标


| 指标 | 计算 | 说明 |
| --- | --- | --- |
| 销售坪效 | 销售额/门店营业面积 | 每坪面积上的营业额(1坪=3.3平方米) |
| 租金坪效  | 租金/门店营业面积  |  |
| 销售比 | (租金成本+物管费)/销售额 |  |
|  |  |  |
|  |  |  |


ROI: 投资回报率 = 利润/投资额
