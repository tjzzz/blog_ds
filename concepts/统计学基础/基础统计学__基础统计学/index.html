    基础统计学

    所属 Topic：统计学基础 · 类型：概念

    统计学的相关知识点在ds中使用的会比较多。

    统计学是一门研究数据怎么收集、整理、分析、解释数据，并从数据中得出结论的学科。按照应用范围分可以有数理统计、经济统计、生物统计等等方向。

    **基础统计学**主要包含两大研究内容：描述统计学、推断统计学

    1. 描述统计学#

    涉及数据收集、处理和描述的统计方法。我们在日常工作中面对数据的时候，如何去描述和刻画这些数据就需要用到描述统计相关的内容。

    1.1 数据收集#

    数据收集来源可以有很多，比如：
    - 公开渠道、统计年鉴等等
    - 调查问卷，可以通过抽样技术的方法进行抽样调查，对于调查问卷获取的数据，还需要对结果的信度和效度做检验：调查问卷的信度、效度
    - 实验方式：通过实验方式的方式来获取一些实验数据

    如果通过实验设计的方式，那么可以进行 ab-test 等试验评估方式；
    如果是观测性研究，那么可能需要使用因果推断相关方法。

    1.2 数据的描述#

    可以用一些基础的统计量进行数据的描述，比如：

    水平的度量#

    平均数、中位数/分位数、众数
    - 如果数据左偏，则均值 < 中位数 < 众数
    - 右偏， 众数 < 中位数 < 均值

    波动的度量#

    • 极差
    • 四分位差
    • 方差和标准差
    • 变异系数 v=s/\bar x

    偏度#

    衡量数据分布的不对称性，也叫做偏态、偏度系数，它表示的是概率分布密度曲线相对于平均值的不对称程度。定义如下（3阶矩）：
    $$SK = E[(\frac{X-\mu}{\sigma})^3] $$
    如果 SK > 0，正偏，右偏态；
    如果 SK < 0，负偏，左偏态。

    峰度#

    4阶矩：K = E[(\frac{X-\mu}{\sigma})^4] - 3。

    • K > 0：高峰度，通常表示分布尾部更厚、极端值更多；
    • K < 0：低峰度，通常表示分布相对更平坦、尾部更薄。

    1.3 数据的处理与分析#

    在一般进行数据分析的时候，除了进行基础的描述性统计量、数据可视化展现之后，可能还会对变量之间的基本关系去做一些分析探索。比如：
    - 分类型变量是否有关联。可以使用分类变量的推断相关的方法
    - 分类变量vs数值变量之间的关系以及是否显著，可以使用方差分析的方法
    - 数值型vs数值型：相关系数、回归分析

    数据质量#

    统计分析的前提是数据本身可信。很多统计结论出错，并不是因为模型复杂度不够，而是因为数据在采集、口径、清洗或样本覆盖上已经存在问题。

    常见的数据质量问题包括：

    • 缺失值：字段为空、埋点未上报、部分样本缺失
    • 异常值：极端大/小值、明显不符合业务逻辑的取值
    • 重复值：用户、订单、事件被重复记录
    • 口径不一致：同一个指标在不同表、不同团队中定义不同
    • 时间窗口不一致：统计周期、曝光窗口、转化窗口没有对齐
    • 样本偏差：样本不能代表总体，比如只覆盖活跃用户或某一端用户
    • 数据延迟：T+1、实时、离线链路之间存在同步差异
    • 埋点问题：漏埋、错埋、重复埋点、版本不一致

    在正式做统计分析前，建议先完成基础的数据质量检查：

    • 字段完整性：缺失率、唯一值数量、枚举值范围
    • 数值合理性：最大/最小值、分位数、异常点
    • 样本覆盖：人群、渠道、端、时间段是否符合分析目标
    • 指标口径：分子、分母、过滤条件、去重逻辑是否明确
    • 数据一致性：不同数据源、不同计算链路之间是否能对齐

    更详细的整理放在：数据质量

    数据可视化索引#

    基础统计中只需要知道：可视化是描述统计和探索性分析的重要手段，用来帮助我们理解数据分布、变量关系、异常点和分组差异。具体内容建议放在数据模块中维护。

    常见可视化场景：

    • 看分布：直方图、密度图、箱线图
    • 看关系：散点图、相关矩阵、热力图
    • 看分组差异：柱状图、箱线图、分组折线图
    • 看时间变化：折线图、面积图
    • 看构成：堆叠柱状图、饼图/环图（慎用）

    相关系数#

    相关系数用于衡量两个变量之间关系的方向和强弱，通常取值范围为 [-1, 1]：

    • r > 0：正相关，一个变量变大时，另一个变量倾向于变大
    • r < 0：负相关，一个变量变大时，另一个变量倾向于变小
    • r = 0：无线性相关，但不代表两个变量完全无关系
    • |r| 越接近 1，关系越强；越接近 0，关系越弱

    常见相关系数可以按变量类型和关系形态选择：

    方法 适用场景 关注点 备注
    Pearson 相关系数 两个连续数值变量，关系近似线性 线性相关 对异常值敏感，常用于正态 / 近似正态数据
    Spearman 等级相关系数 两个变量可排序，关系不一定线性但单调 单调相关 基于秩，抗异常值能力更强
    Kendall 等级相关系数 样本量较小或更关注排序一致性 排序一致性 比 Spearman 更保守，解释为一致 / 不一致排序对
    点二列相关 一个二分类变量 + 一个连续变量 分组与数值变量关系 可理解为二分类变量场景下的 Pearson
    Phi 系数 两个二分类变量 二元变量关联 与 2x2 列联表相关

    Pearson 相关系数公式：

    r = \frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i-\bar{x})^2}\sqrt{\sum_{i=1}^{n}(y_i-\bar{y})^2}}

    使用相关系数时需要注意：

    • 相关不等于因果：两个变量相关，不代表一个变量导致另一个变量变化
    • 相关系数主要描述关系强弱，不直接说明业务机制
    • Pearson 只刻画**线性关系**，非线性关系下可能低估变量关系
    • 异常值可能显著影响相关系数，分析前应先画散点图
    • 分组结构可能造成辛普森悖论，需要分层检查
    • 时间序列数据容易出现伪相关，需要考虑趋势、季节性和自相关

    在数据分析中的常见用法：

    • EDA 阶段探索变量关系
    • 建模前检查特征冗余和多重共线性
    • 指标体系中识别指标之间的联动关系
    • 业务分析中提出可能的机制假设，再结合实验或因果方法验证

    2 推断统计学#

    利用样本数据来推断总体特征的统计学方法。

    描述统计关心「样本数据长什么样」，推断统计关心「能否根据样本推断总体」。在数据分析、实验分析、市场研究中，我们通常不可能观察到全部总体，只能拿到样本，因此需要用推断统计处理不确定性。

    2.1 基本概念#

    概念 含义 例子
    总体 研究对象的完整集合 某产品所有活跃用户
    样本 从总体中抽取的一部分观测 抽取 10 万名用户做问卷或实验
    参数 总体的真实特征，通常未知 总体均值 \mu、总体比例 p
    统计量 由样本计算得到的量，用来估计参数 样本均值 \bar{x}、样本比例 \hat{p}
    抽样误差 样本统计量与总体参数之间的随机差异 抽到不同用户，转化率会有波动
    标准误 统计量抽样分布的标准差，衡量估计的不确定性 样本均值标准误 SE=s/\sqrt{n}
    抽样分布 多次重复抽样后，某个统计量形成的分布 多次抽样得到的一组样本均值分布

    中心极限定理#

    中心极限定理说明：当样本量足够大时，样本均值的抽样分布会近似服从正态分布，即使原始数据本身不服从正态分布。

    这也是很多统计推断方法可以在大样本场景下使用正态近似的基础，比如均值估计、比例估计、AB 实验中的转化率差异检验等。

    参数估计与假设检验的区别#

    • 参数估计：回答「总体指标大概是多少」，例如估计总体平均消费金额、总体转化率
    • 假设检验：回答「某个差异/效果是否足够显著」，例如判断 A/B 两组转化率是否存在统计显著差异

    推断统计常见内容包括：参数估计、置信区间、假设检验、样本量估算、统计功效等。
