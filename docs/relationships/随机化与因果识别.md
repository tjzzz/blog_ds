# 随机化与因果识别

[AB 实验](../concepts/%E5%AE%9E%E9%AA%8C%E8%AE%BE%E8%AE%A1%E4%B8%8EAB%E6%B5%8B%E8%AF%95/AB%E5%AE%9E%E9%AA%8C.md)通过随机分配降低处理组与对照组在处理前系统性不同的风险，因此能为[潜在结果](../concepts/%E5%9B%A0%E6%9E%9C%E6%8E%A8%E6%96%AD/%E6%BD%9C%E5%9C%A8%E7%BB%93%E6%9E%9C.md)框架提供反事实比较。这个关系依赖实际执行：分流异常、跨组干扰、选择性流失或指标口径变化都需要单独诊断。

无法随机化时，观察性方法需要明确替代的识别假设，不能仅凭处理前后变化声称因果效果。
