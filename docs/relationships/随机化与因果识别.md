# 随机化与因果识别

[AB 实验](../entities/AB实验.md)通过随机分配降低处理组与对照组在处理前系统性不同的风险，因此能为[潜在结果](../entities/潜在结果.md)框架提供反事实比较。这个关系依赖实际执行：分流异常、跨组干扰、选择性流失或指标口径变化都需要单独诊断。

无法随机化时，观察性方法需要明确替代的识别假设，不能仅凭处理前后变化声称因果效果。
