# 实验效率与方差缩减

在效应大小和其他设计条件相同时，结果指标的噪声越小，估计越精确。[CUPED](../concepts/%E5%AE%9E%E9%AA%8C%E8%AE%BE%E8%AE%A1%E4%B8%8EAB%E6%B5%8B%E8%AF%95/CUPED.md)尝试利用处理前信息降低这部分噪声，因此可能在相同样本量下提高检出能力。

这不意味着可以省略样本量规划：实际收益依赖协变量与结果的关系、缺失情况及实施方式。应在分析计划中记录调整规则，并同时报告原始与调整后的结果。
