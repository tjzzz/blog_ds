[Faster Implicit Matrix Factorization](https://link.zhihu.com/?target=http%3A//www.benfrederickson.com/fast-implicit-matrix-factorization/) -包含用于实现隐式矩阵分解的ALS算法；

[mrec recommender systems library](https://link.zhihu.com/?target=http%3A//mendeley.github.io/mrec/) - 包含一些重要的方法，如基于矩阵分解的学习到排序的方法；

[lightfm](https://link.zhihu.com/?target=https%3A//github.com/lyst/lightfm) -能够实现协同推荐；

[logistic-mf](https://link.zhihu.com/?target=https%3A//github.com/MrChrisJohnson/logistic-mf) -能够实现逻辑矩阵分解；

[Surprise Lib](https://link.zhihu.com/?target=http%3A//surpriselib.com/) -这个库提供了几种典型的算法（SVD ++，kNN ...），还包含一些用于数据处理和评估的工具；

[Python-recsys](https://link.zhihu.com/?target=https%3A//github.com/ocelma/python-recsys) - 开发时间并不长的一个库；

[crab](https://link.zhihu.com/?target=https%3A//github.com/muricoca/crab)-一个相对完整的算法库。
