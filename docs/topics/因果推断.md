# 因果推断

## 核心问题

观察到的结果变化，有多少能够归因于干预？关键在于构造可信的反事实，并写清让比较成立的识别假设。

## 知识地图

- [导论](../03_统计/CausalAnalysis/01_因果推断导论.md)：相关、干预与反事实。
- [潜在结果框架](../03_统计/CausalAnalysis/04_潜在结果框架_ITE_ATE_ATT_CATE.md)：个体和平均处理效应。
- [偏差与识别假设](../03_统计/CausalAnalysis/06_偏差与识别假设_混杂选择偏差内生性.md)：混杂、选择偏差与内生性。
- [无实验场景评估决策树](../03_统计/CausalAnalysis/03_无实验场景效果评估决策树.md)：依据可获得的对照和时间结构选择设计。
- [方法总览](../03_统计/CausalAnalysis/MOC_因果推断体系.md)：DID、匹配、RDD、IV 与合成控制。

## 关键关系

[随机化与因果识别](../relationships/随机化与因果识别.md)连接实验和观察性研究。每个方法页后续应补充适用前提、主要威胁、诊断方法和原始来源。
