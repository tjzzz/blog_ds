# 因果推断

在随机实验或观察数据中建立可信反事实，并明确识别假设。

## 关键问题

没有直接可见的反事实时，怎样评估干预效果？

## 建议阅读路线

定义处理和结果 → 识别混杂与选择偏差 → 选择实验或准实验设计 → 诊断识别假设。
