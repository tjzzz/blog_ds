## 1. 可知：搭建业务指标
第一步最基础的就是结合业务场景，搭建相关的指标体系。

|      | 说明             |
|:-----|:---------------|
| 核心指标 | 作为衡量部门kpi工作的指标 |
| 观测指标 | 需要关注的指标        |  


核心指标是指业务最关注的指标，比如收入、DAU、停留时长等等。
