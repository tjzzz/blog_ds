# 潜在结果

**定义**：同一研究单元在接受干预与不接受干预两种状态下，各自可能出现的结果。个体效应是两者之差，但同一时刻只能观察到其中一种状态。

**推论**：因果评估必须用其他单元、其他时间或模型假设构造缺失的反事实。平均处理效应及其目标人群需要事先说清。
