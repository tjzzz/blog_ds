## Mental Model

普通 AB 假设「**每个用户互不影响**」（我的处理只改变我，不改你）。但社交/双边/供需产品里，A 被干预会**溢出**影响 B——这时「随机分人」就污染了。

```
理想(无干扰)：  A组变好，B组不变  ⇒ 干净对比
现实(有网络)：  A组变好 → 通过社交/供需 把B也带变 ⇒ 对照不再纯净
```

> **一句话**：只要用户之间存在连接（社交关注、同一市场供需、地理位置邻近），一个单元的处理就会**溢出**到另一个单元，破坏「对照纯净」这一 RCT 根基。这是社交/双边产品最容易被忽略却最致命的坑。

---

## 📊 关键概念

| 概念 | 含义 |
|------|------|
| **SUTVA** | 稳定单元处理假设：一个单元的结果不受其他单元的处理影响。**网络效应下被违反** |
| **溢出/干扰** | 处理从实验单元扩散到对照单元（直接/间接） |
| **网络效应** | 用户价值随连接数变化（社交、双边市场） |
| **双边市场干扰** | 司机/乘客、买家/卖家同市场相互牵引 |

### 解法路线
| 方法 | 思路 | 适用 |
|------|------|------|
| **集群随机 (Cluster Randomization)** | 以「社群/城市/子图」为单元整体随机，而非个人 | 社交圈、地理市场 |
| **graph-cluster** | 按图结构切分连通子图再随机 | 强连接网络 |
| **switchback 实验** | 时间上交替切换策略，自身前后对照 | 时序/供给系统（Uber/DoorDash/LinkedIn） |
| **离群/隔离设计** | 找互不连通的子网分别实验 | 可分割网络 |

## 🎯 实战要点
- **先判断是否会有溢出**：社交、评论、推荐流、供需匹配——基本都有
- **单元选错 = 实验白做**：个人级随机在社交产品里往往无效，改集群/子图/时空切换
- **与 [06_HTE与Uplift个性化](../../methods/%E5%AE%9E%E9%AA%8C%E8%AE%BE%E8%AE%A1%E4%B8%8EAB%E6%B5%8B%E8%AF%95/ab%E5%AE%9E%E9%AA%8C__06_HTE%E4%B8%8EUplift%E4%B8%AA%E6%80%A7%E5%8C%96.md) 叠加**：个性化投放还要注意「对邻居的溢出」
- **与 [05_MAB与客户分群路由](../../methods/%E5%AE%9E%E9%AA%8C%E8%AE%BE%E8%AE%A1%E4%B8%8EAB%E6%B5%8B%E8%AF%95/ab%E5%AE%9E%E9%AA%8C__05_MAB%E4%B8%8E%E5%AE%A2%E6%88%B7%E5%88%86%E7%BE%A4%E8%B7%AF%E7%94%B1.md) 冲突**：MAB 的快速流量倾泻在强网络效应下会放大污染
