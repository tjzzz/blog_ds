## Mental Model

频率派问「**假设无差异，看到这数据有多怪？**」（p 值）。
贝叶斯直接问「**基于已有信念+数据，新策略比旧好的概率是多少？**」（胜率）。

```
频率派：P(数据 | H0)                ← 条件概率，绕
贝叶斯：P(新>旧 | 数据) = 胜率      ← 直接是你想知道的事
```

> **一句话**：贝叶斯胜率 = 「在看完数据后，治疗组真比对照组好的**后验概率**」。它天生回答业务最想问的问题，且**天然顺序有效**——随时看、随时停都不会让假阳性失控。

---

## 📊 核心机制

| 环节 | 说明 |
|------|------|
| 先验 Prior | 实验前的信念（如「新策略有 50% 概率更好」），用分布表示 |
| 似然 Likelihood | 当前实验数据对参数的支持度 |
| 后验 Posterior | 先验 × 似然 ∝ 后验；实验进行中持续更新 |
| **胜率** | 后验分布中 P(θ_treatment > θ_control) |
| **可信区间 CrI** | 后验的 95% 区间（「参数有 95% 概率落在这」，频率派 CI 不能这么说） |

### 为什么「天然顺序有效」
频率派的 p 值在「中途偷看」时会膨胀假阳性（见 [03_序贯分析](../../methods/%E5%AE%9E%E9%AA%8C%E8%AE%BE%E8%AE%A1%E4%B8%8EAB%E6%B5%8B%E8%AF%95/ab%E5%AE%9E%E9%AA%8C__03_%E5%BA%8F%E8%B4%AF%E5%88%86%E6%9E%90.md)）。贝叶斯后验**不存在「看几次」的概念**——它只是「给定当前累积数据，参数的分布」。你第 1 天看和第 30 天看，都是同一套条件概率更新，没有「多次检验」的膨胀。

---

## 🎯 实战用法

- **汇报直观**：「新策略有 92% 概率优于旧策略」比「p=0.03」好懂 10 倍，业务方秒懂。
- **随时可做决策**：胜率 > 95% 就上线，不用等固定样本量。
- **Thompson Sampling 用它做分流**：按后验采样分配流量（见 [05_MAB与客户分群路由](../../methods/%E5%AE%9E%E9%AA%8C%E8%AE%BE%E8%AE%A1%E4%B8%8EAB%E6%B5%8B%E8%AF%95/ab%E5%AE%9E%E9%AA%8C__05_MAB%E4%B8%8E%E5%AE%A2%E6%88%B7%E5%88%86%E7%BE%A4%E8%B7%AF%E7%94%B1.md)）。

---

## ⚠️ 常见误读（重点）

| 误读 | 真相 |
|------|------|
| 「胜率 95% = 长期有 95% 把握赢」 | 错。它是对**当前后验**的概率陈述，不保证长期错误率 |
| 「贝叶斯比 p 值更好、是银弹」 | 否。它只是**沟通更直观 + 顺序有效**，但**依赖先验选择**，且**不保证频率派错误率** |
| 「不用管 peeking 了」 | 对推断本身成立；但**流量效率/因果解读**仍需设计（见 [05_MAB与客户分群路由](../../methods/%E5%AE%9E%E9%AA%8C%E8%AE%BE%E8%AE%A1%E4%B8%8EAB%E6%B5%8B%E8%AF%95/ab%E5%AE%9E%E9%AA%8C__05_MAB%E4%B8%8E%E5%AE%A2%E6%88%B7%E5%88%86%E7%BE%A4%E8%B7%AF%E7%94%B1.md)、[07_网络效应与干扰](ab%E5%AE%9E%E9%AA%8C__07_%E7%BD%91%E7%BB%9C%E6%95%88%E5%BA%94%E4%B8%8E%E5%B9%B2%E6%89%B0.md)） |

> 🛠 **平台真实做法**：后端常用**频率派序贯**控错率（保证严谨），前端用**贝叶斯胜率**做汇报（保证直观）。两者并存，不是二选一。

## 🔍 贝叶斯 vs 频率派（对照表）

| 维度 | 频率派 ([01_假设检验与p值](../../methods/%E5%AE%9E%E9%AA%8C%E8%AE%BE%E8%AE%A1%E4%B8%8EAB%E6%B5%8B%E8%AF%95/ab%E5%AE%9E%E9%AA%8C__01_%E5%81%87%E8%AE%BE%E6%A3%80%E9%AA%8C%E4%B8%8Ep%E5%80%BC.md)) | 贝叶斯胜率 |
|------|------------------------------|-----------|
| 回答的问题 | P(数据\|H0) | P(新>旧\|数据) |
| 顺序有效 | ❌ 需序贯修正 | ✅ 天然 |
| 依赖先验 | 否 | 是 |
| 长期错误率保证 | ✅ 可严格控 | ⚠️ 不保证 |
| 业务沟通 | 绕（p 值难懂） | 直（胜率直观） |
| 典型用途 | 上线裁决、论文 | Dashboard 汇报、MAB 分流 |
