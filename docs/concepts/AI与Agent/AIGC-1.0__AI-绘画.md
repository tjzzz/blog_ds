1. **Leonardo**：基于Stable Diffusion模型，提供图生图、AI修图等功能，无需翻墙即可使用，每天免费生成150张图。
2. **Stable Diffusion**：虽然需要下载安装，但对电脑配置要求较高，免费无任何限制，适合有一定基础的技术人员。
3. **Playground AI**：基于Stable Diffusion模型，也可以使用DALL-E 2去绘图（收费版），免费版本每天可提供1000张的图片额度。
4. **BlueWillow**：操作界面简单易用，出图速度快，完全免费，但图片质量有待提高。
5. **Lexica**：基于Stable Diffusion模型，丰富的Prompt资源，图像生成速度快，操作简单，每月免费100张图片生成。
6. **Fotor**：提供AI文生图、图生图、AI卡通头像生成等功能，无需翻墙，每天免费10张图片。
7. **Bing Image Creator**：基于DALL-E 2的AI绘图工具，支持中文指令生成图片，每天有25次快速出图的机会。
8. **Vega AI**：国内首个在线训练应用AI创作平台，提供文字生图、图片生图等功能，完全免费。
9. **阿里通义万相**：阿里云推出的AI绘画创作大模型，每日有50次免费使用。
10. **WHEE**：美图基于其视觉大模型MiracleVision推出的AI图片和绘画创作平台。
