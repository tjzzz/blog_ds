# 3 零售企业本身的成本与管理


供应链管理

首先，新零售下的供应链管理是以消费者为中心的，不再是被动的，而应该是主动的加入到整个环节中去，如商品选择、销售预测、动态定价、自动补货、采购计划等职能。
