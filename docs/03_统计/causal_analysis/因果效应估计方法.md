## 2. 假设个体依据可测变量选择是否参加——匹配估计

匹配估计的基本思路：
对处理组或者对照组中的每个个体，在可测变量x维度上，去另外一个组去找相似的个体。 然后认为y_i-y_j是个人i的处理效应。最后将每个个体的处理效应进行平均，即可得到**匹配估计量**
