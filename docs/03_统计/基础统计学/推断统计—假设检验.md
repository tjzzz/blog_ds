假设检验其实与参数估计类似，只是描述的角度不同。

# 1. 假设检验的基本原理

简单说：假设检验就是先对总体参数提出某种假设，然后根据抽取到的样本数据，判断样本证据是否足够强，从而决定是否拒绝原假设。

## 1.1 基本步骤

1. 提出原假设与备择假设，例如：

$$ H_0: \mu =\mu_0, H_1: \mu  > \mu_0 $$

2. 选择合适的检验统计量，例如 Z 统计量、t 统计量、卡方统计量、F 统计量等；
3. 设定显著性水平 $\alpha$，常见取值为 0.05 或 0.01；
4. 根据样本数据计算检验统计量和 p-value；
5. 比较 p-value 与 $\alpha$，决定是否拒绝原假设；
6. 结合业务背景解释差异是否有实际意义。

## 1.2 p-value

p-value 表示：**在原假设成立的前提下，观察到当前样本结果或比当前结果更极端结果的概率**。

常见判断方式：

- 如果 p-value < $\alpha$，说明当前结果在原假设下较少发生，因此拒绝原假设；
- 如果 p-value >= $\alpha$，说明当前证据不足，不能拒绝原假设。

注意：

- p-value 不是「原假设为真的概率」；
- p-value 小不代表效果大，只代表在当前假设下结果较不容易由随机波动解释；
- p-value 不显著不代表没有效果，可能是样本量不足、方差过大或指标噪声太高；
- 在业务分析中，需要同时看 p-value、效应量、置信区间和业务价值。

## 1.3 显著性水平与两类错误

### 第一类错误

第一类错误也叫 $\alpha$ 错误：**原假设为真，但错误地拒绝了原假设**。

在 AB 实验中，可以理解为：实际上 A/B 没有差异，但我们误判为有差异。显著性水平 $\alpha$ 就是事先愿意承受的第一类错误概率。

### 第二类错误

第二类错误也叫 $\beta$ 错误：**原假设为假，但没有拒绝原假设**。

在 AB 实验中，可以理解为：实际上 A/B 有差异，但我们没有检验出来。

### 统计功效

统计功效（power）定义为：

$$
Power = 1 - \beta
$$

它表示当真实效果存在时，实验能够检验出这个效果的概率。

统计功效受以下因素影响：

- 样本量：样本量越大，功效通常越高；
- 效应量：真实差异越大，越容易检验出来；
- 方差/噪声：数据波动越大，越难检验出来；
- 显著性水平：$\alpha$ 越大，越容易拒绝原假设，但第一类错误风险也更高。

在实验设计中，通常会在实验前进行样本量估算，确保实验有足够功效检出业务上关心的最小效果。

## 1.4 置信区间与假设检验的关系

置信区间用于描述参数估计的不确定性。比如 95% 置信区间可以理解为：如果重复抽样很多次，用同样方法构造区间，大约 95% 的区间会覆盖真实参数。

在双侧检验中，置信区间和假设检验可以相互对应：

- 如果 95% 置信区间不包含原假设对应的值，通常意味着在 $\alpha=0.05$ 下显著；
- 如果 95% 置信区间包含原假设对应的值，通常意味着在 $\alpha=0.05$ 下不显著。

业务解释中，置信区间往往比单独的 p-value 更有信息量，因为它能同时体现方向、大小和不确定性。

# 2. 均值的比较：t 检验

均值的比较一般可以用 t 检验，根据设计方式的不同可分为如下两类。

## 2.1 配对样本 t 检验

配对样本，即相同的用户参与了不同的测试。采用相同的用户分别参加两种不同的测试，好处是排除了用户的个体干扰，面临的问题是需要对用户先接触哪个、后接触哪个做好平衡，不能让两个处理之间相互影响。比如测试两种药品，先服用 A 药后，已经对用户产生了影响，再去服用 B 药物的话就无法准确地看出效果了。

美食评判中，美食专家们都是品尝完一道菜之后需要漱口，然后才开始品尝下一道菜，就是这个原因。

其中 D 表示两个不同测试之间的差别。

$$t=\frac{\hat D}{S_D/\sqrt n}$$

## 2.2 双总体 t 检验

即不同的用户参与了不同的测试，一个 A 组，一个 B 组。通过两组效果的差异进行比较。

假设两个总体分别为 X, Y，令 $Z=X-Y$。

假设条件：

* 两组样本不相关；
* 两组样本近似服从正态分布，或样本量足够大时可依赖中心极限定理。

在以上的前提假设下，$Z=X-Y$ 也应该近似服从正态分布。且有：

$$ E(Z) = E(X)- E(Y)=\mu_1-\mu_2$$
$$ Var(Z) = Var(X-Y)= Var(X) + Var(Y)$$

均值的估计可以用样本均值差 $\bar x - \bar y$，而方差的估计需要分情况讨论。

* $\sigma_1,\sigma_2$ 已知：

$$Z=\frac{\bar x-\bar y -(\mu_1 - \mu_2)}{\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}}\sim N(0,1)$$

* $\sigma_1,\sigma_2$ 未知：
    * 若假设 $\sigma_1=\sigma_2$，可以使用合并方差估计：

$$ t=\frac{\bar x-\bar y -(\mu_1 - \mu_2)}{S_w\sqrt{1/n_1+1/n_2}}\sim t_{n_1+n_2-2}$$

其中联合估计方差：

$$s_w^2=\frac{(n_1-1)s_1^2+(n_2-1)s_2^2}{n_1+n_2 -2}$$

   * 若不假设 $\sigma_1=\sigma_2$，可以使用 Welch t 检验：

$$ t=\frac{\bar x-\bar y -(\mu_1 - \mu_2)}{\sqrt{s_1^2/n_1+s_2^2/n_2}}\sim t_{df'}$$

其中 t 分布的自由度近似为：

$$df'=\frac{(s_1^2/n_1+s_2^2/n_2)^2}{\frac{(s_1^2/n_1)^2}{n_1-1} + \frac{(s_2^2/n_2)^2}{n_2-1}}$$

## 2.3 效应量

除了差异是否显著以外，在实际中还需要注意差异的效应量（effect size），即这个差异究竟有多大。

在业务实验中，一个结果可能统计显著，但提升幅度很小，不一定值得上线；也可能暂时不显著，但方向稳定、置信区间较窄，值得继续扩大样本观察。

# 3. 比例的比较

## 3.1 双比例检验

双总体的比例检验，比例其实可以看做是均值的一种特殊情况，所以双总体比例的比较也可以转化为均值的比较。

设两组样本比例为 $\hat p_1, \hat p_2$，合并比例为：

$$
\hat p=\frac{x_1+x_2}{n_1+n_2}, \quad \hat q = 1-\hat p
$$

则在原假设 $p_1=p_2$ 下：

$$Z=\frac{\hat p_1-\hat p_2 }{\sqrt{\hat p\hat q(\frac{1}{n_1}+\frac{1}{n_2})}}\sim N(0,1)$$

## 3.2 卡方检验

对于分类型变量，另一个常用的检验方法就是卡方检验。卡方检验首先是一种非参数检验方法，其并不依赖于原始数据的分布假定。卡方检验主要应用于分类变量的关联性分析（关于卡方检验的后续再详细介绍）。

对于 2x2 的列联表来说：

|   | 通过 | 失败 | 总计 |
| --- | --- | --- | --- |
| 实验A | a | b | m |
| 实验B | c | d | n |
| 总计 | r | s | N |

$$\chi^2 = \frac{(ad-bc)^2N}{mnrs}$$

## 3.3 Fisher 精确检验

上述说的卡方检验和双比例检验其实都是一种近似。Fisher 精确检验依据超几何分布，根据排列组合的概率来进行计算，适合样本量较小或列联表中期望频数较低的场景。

# 4. 常见检验方法选择

| 问题类型 | 常见方法 | 说明 |
|---|---|---|
| 两组均值比较，独立样本 | 独立样本 t 检验 / Welch t 检验 | 方差不齐时优先考虑 Welch t 检验 |
| 两组均值比较，配对样本 | 配对 t 检验 | 同一对象前后对比或匹配样本 |
| 多组均值比较 | 方差分析 ANOVA | 显著后通常需要进一步做多重比较 |
| 两组比例比较 | 双比例 Z 检验 | 常用于转化率、点击率等指标 |
| 分类变量关联 | 卡方检验 / Fisher 精确检验 | 小样本时考虑 Fisher 精确检验 |
| 数据不满足参数检验假设 | 非参数检验 | 如 Mann-Whitney U、Wilcoxon、Kruskal-Wallis 等 |
