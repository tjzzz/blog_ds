# 07. 方法：合成控制法

合成控制法适合评估单个处理对象的策略效果。

## 1. 适用场景

- 处理对象很少，甚至只有一个；
- 处理发生在国家、城市、门店、业务线、版本等聚合单元上；
- 有较长的处理前时间序列；
- 可以找到多个未处理单元作为 donor pool。

业务例子：某国家市场上线新广告变现策略，没有办法随机抽用户做 AB，可以用其他未上线国家加权合成一个“如果没上线”的反事实。

## 2. 核心直觉

```text
用多个未处理单元的加权组合，拟合处理单元在处理前的走势。
如果处理前拟合得好，那么处理后合成组可以作为反事实对照。
```

## 3. 方法步骤

1. 确定处理单元和处理时间；
2. 选择未处理单元池；
3. 选择处理前特征和结果序列；
4. 求一组权重，使合成组在处理前尽量接近处理组；
5. 比较处理后真实处理组和合成组差异；
6. 做 placebo 和敏感性分析。

## 4. 关键诊断

| 诊断 | 目的 |
|---|---|
| 处理前拟合误差 | 判断合成反事实是否可信 |
| placebo test | 看未处理单元假装被处理是否也出现类似效果 |
| leave-one-out | 检查结果是否依赖某个 donor |
| donor pool 合理性 | 避免把不相似或受污染单元放进去 |

## 5. 和 DID 的区别

| 维度 | DID | 合成控制法 |
|---|---|---|
| 对照组 | 通常是一个自然对照组 | 多个单元加权合成 |
| 处理单元数量 | 可多个 | 常用于单个或少数处理单元 |
| 关键假设 | 平行趋势 | 处理前可被合成组拟合 |
| 可解释性 | 简洁 | 可解释哪些 donor 贡献了反事实 |

## 6. 常见误用

- 处理前拟合很差仍强行解释处理后差异；
- donor pool 中包含被间接影响的单元；
- 处理时间附近有其他同时发生的重要事件；
- 只看结果曲线，不做 placebo。
