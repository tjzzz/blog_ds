DID 用于评估某个处理在上线前后带来的变化，同时用未处理组扣除共同时间趋势。

## 1. 适用场景

- 有处理组和对照组；
- 有处理前和处理后的数据；
- treatment 发生在某个明确时间点；
- 不能随机分组，但可以找到类似的未处理对象。

业务例子：某国家上线广告策略，其他相似国家未上线；比较上线前后收入变化，并扣除其他国家同期自然变化。

## 2. 基本估计量

| 组别 | 处理前 | 处理后 | 差值 |
|---|---:|---:|---:|
| 处理组 | $Y_{T,pre}$ | $Y_{T,post}$ | $Y_{T,post}-Y_{T,pre}$ |
| 对照组 | $Y_{C,pre}$ | $Y_{C,post}$ | $Y_{C,post}-Y_{C,pre}$ |

DID：

$$
DID = (Y_{T,post}-Y_{T,pre}) - (Y_{C,post}-Y_{C,pre})
$$

## 3. 简单例子

假设国家 A 上线广告变现策略，国家 B 未上线，指标是 ARPDAU：

| 组别 | 上线前 | 上线后 | 前后变化 |
|---|---:|---:|---:|
| 国家 A：上线策略 | 0.10 | 0.16 | +0.06 |
| 国家 B：未上线 | 0.08 | 0.11 | +0.03 |

DID 估计量：

```text
DID = (0.16 - 0.10) - (0.11 - 0.08)
    = 0.06 - 0.03
    = 0.03
```

含义是：扣除同期自然增长后，新策略带来的净增量约为 **+0.03 ARPDAU**。

## 4. 回归形式与显著性检验

$$
Y_{it}=\alpha + \beta Treat_i + \gamma Post_t + \delta(Treat_i \times Post_t) + \epsilon_{it}
$$
- 每个个体i在时间t的表现，由个体因子 + 时间因子 + 交互项决定


其中 $\delta$ 是 DID 估计的处理效应。

显著性检验本质上是检验交互项系数：

$$
H_0: \delta = 0
$$

如果 `Treat × Post` 的 p-value 小于显著性水平，例如 0.05，可以认为策略净效果显著不为 0。

实际使用时，标准误最好按实验单元聚类修正，例如按国家、城市、门店或用户聚类：

```python
model = smf.ols(
    "y ~ treat:post + C(unit_id) + C(date)",
    data=df
).fit(
    cov_type="cluster",
    cov_kwds={"groups": df["unit_id"]}
)
```

## 5. 核心假设：平行趋势

如果没有 treatment，处理组和对照组的趋势应该相同。

因此必须检查：

- 处理前多期趋势是否接近；
- 是否存在处理前提前反应；
- 对照组是否受到其他冲击；
- 处理组是否同时发生其他变化。

## 6. 诊断与稳健性

| 检查 | 目的 |
|---|---|
| 处理前趋势图 | 检查平行趋势 |
| placebo test | 假装提前发生 treatment，看是否出现假效果 |
| 换对照组 | 检查结果是否依赖某个对照选择 |
| 加时间固定效应 | 控制共同时间冲击 |
| 加个体固定效应 | 控制个体不随时间变化的差异 |
| 事件研究图 | 查看动态处理效应 |

## 7. 常见误用

- 只有处理前后一共两期，却完全无法验证趋势；
- 对照组业务环境和处理组差异过大；
- treatment 时间不清晰；
- 多批次上线时仍使用简单 DID，忽略 staggered adoption 问题；
- 指标受节假日、版本、外部投放影响，却没有控制。
