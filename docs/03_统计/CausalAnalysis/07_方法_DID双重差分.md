# 07. 方法：DID 双重差分

DID 用于评估某个处理在上线前后带来的变化，同时用未处理组扣除共同时间趋势。

## 1. 适用场景

- 有处理组和对照组；
- 有处理前和处理后的数据；
- treatment 发生在某个明确时间点；
- 不能随机分组，但可以找到类似的未处理对象。

业务例子：某国家上线广告策略，其他相似国家未上线；比较上线前后收入变化，并扣除其他国家同期自然变化。

## 2. 基本估计量

| 组别 | 处理前 | 处理后 | 差值 |
|---|---:|---:|---:|
| 处理组 | $Y_{T,pre}$ | $Y_{T,post}$ | $Y_{T,post}-Y_{T,pre}$ |
| 对照组 | $Y_{C,pre}$ | $Y_{C,post}$ | $Y_{C,post}-Y_{C,pre}$ |

DID：

$$
DID = (Y_{T,post}-Y_{T,pre}) - (Y_{C,post}-Y_{C,pre})
$$

## 3. 回归形式

$$
Y_{it}=lpha + eta Treat_i + \gamma Post_t + \delta(Treat_i 	imes Post_t) + \epsilon_{it}
$$

其中 $\delta$ 是 DID 估计的处理效应。

## 4. 核心假设：平行趋势

如果没有 treatment，处理组和对照组的趋势应该相同。

因此必须检查：

- 处理前多期趋势是否接近；
- 是否存在处理前提前反应；
- 对照组是否受到其他冲击；
- 处理组是否同时发生其他变化。

## 5. 诊断与稳健性

| 检查 | 目的 |
|---|---|
| 处理前趋势图 | 检查平行趋势 |
| placebo test | 假装提前发生 treatment，看是否出现假效果 |
| 换对照组 | 检查结果是否依赖某个对照选择 |
| 加时间固定效应 | 控制共同时间冲击 |
| 加个体固定效应 | 控制个体不随时间变化的差异 |
| 事件研究图 | 查看动态处理效应 |

## 6. 常见误用

- 只有处理前后一共两期，却完全无法验证趋势；
- 对照组业务环境和处理组差异过大；
- treatment 时间不清晰；
- 多批次上线时仍使用简单 DID，忽略 staggered adoption 问题；
- 指标受节假日、版本、外部投放影响，却没有控制。
