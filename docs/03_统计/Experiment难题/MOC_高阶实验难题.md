# MOC_高阶实验难题

高阶实验难题的核心不是「会不会做检验」，而是能不能识别：实验结论什么时候不可信、为什么不可信、应该怎么补救。

| 高频问题 | 一句话判断 | 对应文档 |
|---|---|---|
| SRM 样本比例不匹配 | 实际分流比例和配置不一致，优先怀疑分流/埋点/数据链路 | [SRM 样本比例不匹配](高阶实验难题_SRM样本比例不匹配.md) |
| 实验敏感性不足 | 真实有效果但实验检不出来，优先检查样本量、方差、指标和实验机制 | [实验敏感性不足](高阶实验难题_实验敏感性不足.md) |
| 辛普森悖论 | 整体结论和分层结论冲突，优先检查样本结构和混杂变量 | [辛普森悖论](高阶实验难题_辛普森悖论.md) |
| 时序干扰与长期效应 | 短期正向不代表长期正向，必须看时间趋势和周期干扰 | [时序干扰与长期效应](高阶实验难题_时序干扰与长期效应.md) |
| 网络效应与溢出干扰 | 实验组会影响对照组，普通用户级随机可能失效 | [网络效应与溢出干扰](高阶实验难题_网络效应与溢出干扰.md) |
| 触发偏差与幸存者偏差 | 只看触发/留下的人，会破坏随机性 | [触发偏差与幸存者偏差](高阶实验难题_触发偏差与幸存者偏差.md) |
| 多重检验与显著性窥探 | 指标看太多、每天 peek，会增加假阳性 | [多重检验与显著性窥探](高阶实验难题_多重检验与显著性窥探.md) |
| 指标污染与口径漂移 | 指标口径/埋点/数据源变化，会让实验结果失真 | [指标污染与口径漂移](高阶实验难题_指标污染与口径漂移.md) |

## 分析顺序建议

```text
先检查数据质量和 SRM
  → 再看整体核心指标
  → 再看时间趋势
  → 再看关键分层
  → 再看长期/护栏指标
  → 最后给业务决策
```

不要在 SRM、指标污染、时序冲击没排除前，直接讨论 p-value。
