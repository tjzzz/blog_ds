> 核心判断：短期实验结果不一定代表长期效果；时间、周期、节假日、用户学习都会干扰实验结论。

## 1. 业务场景

常见表现：

- 新功能上线前几天点击率提升，几周后回落；
- 推荐策略短期提升点击，但长期降低留存；
- 周末实验正向，工作日负向；
- 大促期间策略有效，平日无效；
- 实验刚上线时用户不熟悉，指标短期下降，后续恢复。

## 2. 高频原因

| 问题 | 解释 |
|---|---|
| 新奇效应 | 用户因为新鲜感短期点击更多 |
| 学习效应 | 用户需要时间适应新界面/新策略 |
| 周期性 | 周末、月初、节假日、发薪日等影响行为 |
| 活动冲击 | 促销、push、渠道投放改变用户结构 |
| 趋势变化 | 大盘自然上涨/下降与实验效果混在一起 |
| 延迟转化 | 曝光后需要多天才发生购买、留存或复购 |

## 3. 识别方法

不要只看实验全周期平均值，要看时间序列：

- 日维度累计效果曲线；
- 每日 treatment-control 差异；
- 周期内核心指标波动；
- 新用户/老用户的适应差异；
- 短期指标和长期指标是否方向一致。

重点判断：

```text
效果是稳定存在，还是只在某几天出现？
效果是在增强、衰减，还是反转？
是否刚好与活动、版本发布、节假日重合？
```

## 4. 处理策略

| 场景 | 处理 |
|---|---|
| 新奇效应 | 延长实验周期，观察效果衰减 |
| 学习效应 | 设置预热期，分析时剔除前几天或单独报告 |
| 周期性 | 覆盖完整业务周期，至少覆盖一个自然周 |
| 活动冲击 | 分活动期/非活动期分析，必要时暂停实验 |
| 延迟转化 | 设置合理转化窗口，不提前下结论 |
| 长期风险 | 保留 holdout 或做反转实验 |

如果策略影响用户习惯、推荐分发、生态供给，建议做长期 holdout，不要只看短期 AB。

## 5. 平台化能力

- 实验报告自动展示每日效果趋势；
- 记录业务活动、版本发布、营销投放日历；
- 支持预热期、观察期、转化窗口配置；
- 支持实验停止进流后继续回收指标；
- 支持长期 holdout 与反转实验。
