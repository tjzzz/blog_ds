# 高阶实验难题：网络效应与溢出干扰

> 核心判断：当一个用户的处理会影响另一个用户，普通用户级随机 AB 就可能失效。

## 1. 业务场景

典型场景：

- 社交产品：实验组用户发内容更多，影响对照组好友的信息流；
- 交易平台：实验组商家补贴改变价格，对照组用户也看到市场变化；
- 打车/外卖：实验组司机调度策略影响全局供需和对照组等待时长；
- 推荐系统：实验组消耗更多优质内容，影响对照组可推荐内容池；
- 广告竞价：实验组出价策略改变市场竞争，影响对照组成本。

## 2. 为什么普通 AB 会错

普通 AB 默认 SUTVA：一个实验单元的结果不受其他实验单元处理影响。

但在网络/市场/生态型业务中，这个假设经常不成立：

- 用户之间互相影响；
- 供给和需求共享资源；
- 排序和推荐共享内容池；
- 价格、补贴、库存、运力存在全局约束。

结果是：对照组不再是真正未受影响的对照组。

## 3. 识别方法

需要问：

- 实验组动作是否会改变平台整体资源分配？
- 实验组用户/商家/司机是否会与对照组互动？
- 实验指标是否依赖全局供需、库存、竞价或排序池？
- 扩量后效果是否明显不同于小流量？

如果小流量正向，扩量后收益下降或反转，要重点怀疑溢出效应。

## 4. 处理策略

| 场景 | 处理 |
|---|---|
| 用户之间强互动 | 按社交图 cluster 随机，而不是单用户随机 |
| 地域供需联动 | 按城市/区域随机，避免同一区域 A/B 混杂 |
| 商家策略影响用户 | 按商家或商圈随机，并限制跨组曝光 |
| 内容池共享 | 做资源隔离或全局 holdout |
| 广告竞价/补贴策略 | 采用市场级实验、geo experiment 或 switchback |

核心原则：实验单元要与干扰边界一致。

## 5. 平台化能力

实验平台需要支持：

- 用户级、商家级、地域级、内容级等多种实验单元；
- cluster randomization；
- geo experiment；
- switchback experiment；
- 实验资源隔离；
- 记录实验之间的资源依赖和冲突关系。
