# CATS





首先定义两条曲线，各自上面两点之间的一个空间衰减函数。

![](../../media/15688875616388/15688982260506.jpg)

简单地说就是，当两个的距离大于某个阈值e时候是0，当小于e时候。距离越近值越大，最终是个0-1上的值。
