## Mental Model

把实验想成**法庭审判**：

```
被告(新策略) 默认无罪 = 零假设 H0「新旧无差异」
检察官(数据) 要证明它有罪 = 备择 H1「新策略有效」
p 值 = 「假设它真的无罪，出现当前这么强(或更强的)证据的概率」
p 很小 ⇒ 证据太不像偶然 ⇒ 判 H0 有罪(显著)
```

> **一句话**：p 值不是「H0 为真的概率」，也不是「新策略有效的把握」。它是「**在 H0 成立的前提下，看到当前数据（或更极端）的概率**」。p 小 = 数据很难用「纯偶然」解释。

---

## 📊 核心概念

| 概念 | 符号 | 含义 | 常见误区 |
|------|------|------|---------|
| 零假设 | H0 | 「新旧无差异 / 无效应」 | 误当「被证伪的假设」 |
| 备择假设 | H1 | 「有效应」 | — |
| **p 值** | p | P(数据\|H0 成立) | 误当 P(H0\|数据)（逆概率） |
| 显著性水平 | α | 允许假阳性上限（常 0.05） | 不是 p 的阈值本身 |
| I 类错误 | 假阳性 | 实际无效应却判显著 | — |
| II 类错误 | 假阴性 | 实际有效却判不显著 | — |
| **统计功效** | 1−β | 有效时应能检出它的概率 | 常被忽略，导致实验白跑 |
| **MDE** | — | 最小可检测效应（能分辨的最小差异） | 越小样本量越大 |

### 样本量与 MDE（对接 [推断统计—参数估计](../%E7%BB%9F%E8%AE%A1%E5%AD%A6%E5%9F%BA%E7%A1%80/%E5%9F%BA%E7%A1%80%E7%BB%9F%E8%AE%A1%E5%AD%A6__%E6%8E%A8%E6%96%AD%E7%BB%9F%E8%AE%A1%E2%80%94%E5%8F%82%E6%95%B0%E4%BC%B0%E8%AE%A1.md)）
两个核心杠杆：
- **方差 σ² 越小 / 样本量 n 越大** → 能检出的 MDE 越小
- 公式直觉：`MDE ∝ σ / √n`（两样本近似）。要 MDE 砍半，需 4× 样本量。

> 样本量计算在 vault 已有专文：[推断统计—参数估计](../%E7%BB%9F%E8%AE%A1%E5%AD%A6%E5%9F%BA%E7%A1%80/%E5%9F%BA%E7%A1%80%E7%BB%9F%E8%AE%A1%E5%AD%A6__%E6%8E%A8%E6%96%AD%E7%BB%9F%E8%AE%A1%E2%80%94%E5%8F%82%E6%95%B0%E4%BC%B0%E8%AE%A1.md)（参数估计）、[基础统计学](../../concepts/%E7%BB%9F%E8%AE%A1%E5%AD%A6%E5%9F%BA%E7%A1%80/%E5%9F%BA%E7%A1%80%E7%BB%9F%E8%AE%A1%E5%AD%A6__%E5%9F%BA%E7%A1%80%E7%BB%9F%E8%AE%A1%E5%AD%A6.md)。本卡只给「在实验语境下怎么用」。

## 🎯 实验语境下的正确用法

1. **事前定样本量**：先定 α、功效(常 0.8)、MDE，反推 n。不要「跑到显著就停」（见 [03_序贯分析](ab%E5%AE%9E%E9%AA%8C__03_%E5%BA%8F%E8%B4%AF%E5%88%86%E6%9E%90.md) 的 peeking 问题）。
2. **p<0.05 只说明「不太可能是偶然」**，不代表效应有业务价值——要看**效应量 + 置信区间**，不是只看星星。
3. **看置信区间(CI)**：「效应估计 ± 误差范围」。CI 跨 0 = 不显著；CI 全在正侧 = 显著且方向明确。

---

## ⚠️ 常见踩坑

| 坑 | 说明 | 解法 |
|----|------|------|
| **Peeking** | 每天看 p 值，显著就停 | 用 [03_序贯分析](ab%E5%AE%9E%E9%AA%8C__03_%E5%BA%8F%E8%B4%AF%E5%88%86%E6%9E%90.md) 或固定样本 |
| **p-hacking** | 换指标/切分人群直到显著 | 预注册指标、多重比较校正（[08_实验治理与护栏](ab%E5%AE%9E%E9%AA%8C__08_%E5%AE%9E%E9%AA%8C%E6%B2%BB%E7%90%86%E4%B8%8E%E6%8A%A4%E6%A0%8F.md)） |
| **把 p 当概率** | 「p=0.03 所以有 97% 把握 H1 对」 | 错。p 是 P(数据\|H0)，非 P(H1\|数据) |
| **样本量不足仍「不显著就放弃」** | 功效不够，检出不了真效应 | 先算样本量，保证功效 |
| **SRM 未查先信** | 分流不均导致结果系统性偏 | 先查样本比例匹配（[08_实验治理与护栏](ab%E5%AE%9E%E9%AA%8C__08_%E5%AE%9E%E9%AA%8C%E6%B2%BB%E7%90%86%E4%B8%8E%E6%8A%A4%E6%A0%8F.md)） |
