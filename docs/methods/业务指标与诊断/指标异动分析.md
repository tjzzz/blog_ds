## 维度归因

| **贡献率算法** | **公式**                                                                                                                                                                  |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 定基法       | sum();count();count(distinct);sum()/sum();sum()/count(distinct)。更多请参考[定基法支持的表达式](https://site.bytedance.net/docs/400/2060/139423/#%E9%80%82%E7%94%A8%E8%8C%83%E5%9B%B4) |
| 占比加权法     | 分子分母都可加的除法。sum()/sum();sum()/count()                                                                                                                                    |
| 剔除法       | 表达式中使用了LOD函数                                                                                                                                                            |


### 加法类型
加法类型相对比较简单，因为总体的变化值可以拆分成各个维度变化值的总和。比如city这个维度，想定位下这周整体gmv下降不同city贡献的情况。

$$维度i的贡献率 = \frac{维度i的变化值}{总的变化值}$$


### 除法指标(分子分母可加)
基本的思路，看某个维度属性的贡献，先假设其他维度属性不变，然后看单独变更这个属性后的变化情况。假设上一周期：
整体分子: a1, a2, a3, a4
整体分母: b1, b2, b3, b4
对比周期：
整体分子: A1, A2, A3, A4
整体分母: B1, B2, B3, B4

对于维度1，其贡献程度就是:

sum(A1, a2, a3, a4) / sum(b1, b2, b3, b4) - sum(B1, a2, a3, a4) / sum(b1, b2, b3, b4)
