# 实验方法选择

| 问题 | 优先检查 | 进入哪条知识线 |
| --- | --- | --- |
| 能随机分配且样本充足？ | 实验单元、指标、样本量、分流质量 | [AB 实验](../entities/AB实验.md) |
| 实验周期或流量受限？ | 是否能用处理前协变量；能否事先约定监测和停止规则 | [CUPED](../entities/CUPED.md)、[序贯分析旧文](../03_统计/ab实验/03_序贯分析.md) |
| 无法随机分配？ | 可用对照、上线时点、识别假设及其可检验性 | [因果推断](../topics/因果推断.md) |
| 用户之间会互相影响？ | 干扰范围、随机化层级、溢出指标 | [网络效应与干扰旧文](../03_统计/ab实验/07_网络效应与干扰.md) |

这张表是**问题分流入口**，不是方法适用性的自动判定。具体方案仍要按业务约束、数据结构和识别假设展开。[旧方法图谱](../03_统计/ab实验/MOC_ab实验方法图谱.md)提供更多方法细节。
