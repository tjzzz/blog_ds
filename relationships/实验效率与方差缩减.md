# 实验效率与方差缩减

在效应大小和其他设计条件相同时，结果指标的噪声越小，估计越精确。[CUPED](../topics/%E5%AE%9E%E9%AA%8C%E8%AE%BE%E8%AE%A1%E4%B8%8EAB%E6%B5%8B%E8%AF%95/%E7%81%B5%E6%95%8F%E5%BA%A6%E4%B8%8E%E6%8F%90%E6%95%88/CUPED.md)尝试利用处理前信息降低这部分噪声，因此可能在相同样本量下提高检出能力。对结果指标做 log / 开方 / 封顶等变换是另一类降低噪声的杠杆：它在重新分配不同用户对噪声与信号的贡献，收益取决于实验让哪类用户以什么方式发生变化，需结合机制与验证评估，不能仅看基线长尾。

这不意味着可以省略样本量规划：实际收益依赖协变量与结果的关系、缺失情况及实施方式。应在分析计划中记录调整规则，并同时报告原始与调整后的结果。
