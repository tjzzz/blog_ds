## 二、全书逻辑主线

```
          临床前研究（PK/PD、动物实验）
                    │
                    ▼
   ┌────────────────────────────────────────┐
   │ I 期：安全性 → 找 MTD（小样本 20–50）   │  ← 第 03、08、09 篇
   └────────────────────────────────────────┘
                    │  推荐 II 期剂量 (MTD / RP2D)
                    ▼
   ┌────────────────────────────────────────┐
   │ II 期：初步疗效 → 筛选药物（30–200）    │  ← 第 04、07 篇（+ I/II 期无缝）
   └────────────────────────────────────────┘
                    │  “有希望”
                    ▼
   ┌────────────────────────────────────────┐
   │ III 期：确证性比较（数百–数千）         │  ← 第 05、06 篇
   └────────────────────────────────────────┘
                    │  获批上市
                    ▼
   ┌────────────────────────────────────────┐
   │ IV 期：长期安全性监测                   │  ← 第 06 篇末尾
   └────────────────────────────────────────┘

   横向主题：随机化（07）、个体化医疗与生物标志物（10）、
            统计基础（02）、自适应思想贯穿全书
```

**核心观点（作者的“务实”立场）：**

1. **书中早期试验（I、II 期）的许多方法采用贝叶斯框架**：样本量小，贝叶斯方法能灵活借用信息、实时更新、自然地处理“边学边做”。
2. **确证性试验（III 期）必须显式评估错误率与功效**：这并不排斥贝叶斯工具，但设计的操作特性须经验证；监管要求另核现行规范。
3. **“自适应”不专属于任何一个学派**：贝叶斯与频率学派都可以自适应；关键是**允许的适应范围、决策规则与最终分析事先设定并验证**，不能中途任意改方案后沿用原误差率。
4. **没有放之四海皆准的设计**：每个试验都有自己的特点，需要用模拟（operating characteristics）来评价设计。

## 三、符号约定

| 符号 | 含义 |
|:---|:---|
| $\phi_T$ | I 期目标毒性概率（target toxicity probability） |
| $\pi_j$ | 第 $j$ 个剂量水平的真实毒性概率 |
| $p_E, p_S$ | 试验药 / 标准药的有效率 |
| $\alpha,\ \beta$ | 第 I 类 / 第 II 类错误率；检验效能 $=1-\beta$ |
| $z_a$ | 标准正态分布的上 $a$ 分位数，$\Pr(Z>z_a)=a$ |
| $\Phi(\cdot)$ | 标准正态分布函数 |
| $\theta$ | 处理效应（如均值差、有效率差、对数风险比） |
| $\mathrm{Beta}(a,b)$ | Beta 分布；$\mathrm{Bin}(n,p)$ 为二项分布 |
| $D$ | 当前累积观察到的数据 |
| DLT / MTD | 剂量限制性毒性 / 最大耐受剂量 |
